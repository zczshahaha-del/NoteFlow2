# NoteFlow 当前功能审计与 V9 映射基线

> 审计日期：2026-09-13
>
> 审计对象：当前 `main` 分支前端代码
> 用途：约束后续 UI 设计只能建立在现有可达功能上，不再凭空增加入口、模式、状态或统计信息。

## 1. 判断口径

功能是否进入设计稿，不以“代码目录里存在某个组件”为唯一依据，而按以下顺序判断：

1. 当前页面是否有真实入口；
2. 入口是否能触发真实状态或业务调用；
3. 用户是否能在当前工作流中到达该状态；
4. 显示的名称、数量和状态是否来自真实数据。

无法满足以上条件的内容不进入 V9 主稿。值得后续接通的能力单独记录，不伪装成当前已有功能。

## 2. 应用外壳

来源：`src/App.tsx`

| 当前真实行为 | V9 处理 |
| --- | --- |
| 登录后进入单一知识工作台，没有全局品牌顶栏 | 保持无顶栏，不再增加 Logo、面包屑、分享或保存状态栏 |
| 桌面端左侧目录为 260px，可收成 52px 图标轨 | 原样保留展开/收起两种状态 |
| 正文始终位于应用底层，并按左右面板占用空间计算阅读宽度 | 保持正文为主层，不额外包一张“纸张卡片” |
| AI 默认关闭；通过右下角 AI 按钮打开 | 默认稿可展示“用户已打开 AI”的真实状态，同时保留关闭后的启动按钮 |
| 桌面 AI 默认 500px，可在 320–680px 间拖拽 | V9 保留左侧拖拽边与折叠行为，不新增固定模式标签 |
| 平板和手机使用目录/AI 抽屉；手机有知识库启动按钮 | 响应式按现有断点和抽屉逻辑呈现 |
| 修改预览时隐藏左右面板，草稿工作台以覆盖层打开 | 不把修改预览或草稿伪装成主工作台常驻区域 |

## 3. 左侧目录

来源：`src/components/DirectoryTree.tsx`、`src/components/AppNav.tsx`

### 默认可见

- 标题“目录”和真实笔记篇数；
- 收起/展开目录；
- “新建”菜单：新建笔记、新建文件夹；
- 全库搜索入口，支持 `⌘/Ctrl + K`；
- 文件夹展开/收起、笔记选择；
- 文件或文件夹的置顶状态；
- 笔记的收藏状态；
- 底部“我的账号”、回收站和设置。

### 条目菜单中的真实操作

- 重命名；
- 移动到其他文件夹或知识库根目录；
- 导出单篇笔记；
- 置顶/取消置顶；
- 收藏/取消收藏，仅笔记；
- 删除；
- 回收站恢复已删除笔记。

### 真实弹层

- 新建文件夹：名称、字符数、创建位置、文件夹搜索、取消、创建；
- 移动项目：当前项目、目标位置、文件夹搜索、取消、移动；
- 删除确认；
- 回收站及恢复；
- 全库搜索；
- 账号菜单和设置。

### 账号与设置

- 我的账号：登录邮箱修改与验证码确认、已登录设备管理、退出登录；
- 设置 / 通用：浅色、深色；
- 设置 / AI 与记忆：长期记忆开关、记忆列表、确认/启用/停用、编辑、删除；
- 设置 / 数据：导出笔记备份、导出完整数据、导入 Markdown/ZIP/JSON 等文件。

### V8 中必须删除的虚构内容

- “最近使用”“我的收藏”“全部笔记”等固定快捷分区；
- 为目录或分区编造的数量；
- 固定品牌区与“个人知识空间”副标题；
- 并不存在的常驻搜索输入框。

## 4. 正文编辑器

来源：`src/components/NoteEditor.tsx`

### 当前可达功能

- 未选择笔记时的空状态；
- 文档标题直接编辑并同步重命名；
- 创建时间、更新时间；
- 文档显示设置：显示/隐藏一级和二级章节编号；
- Tiptap 正文编辑；
- 粘贴或拖拽文件后上传并插入正文；
- 选中文字后出现浮动工具栏：加入对话、加粗、斜体、下划线、删除线、高亮、行内代码、添加/取消链接、无序列表、有序列表、引用、清除格式；
- 添加链接时的地址输入条；
- 有多个标题时显示右侧章节快速导航，悬停后展开标题；
- 手机端以抽屉显示本文目录。

### 代码存在但当前没有可达入口

- 完整文档格式工具栏被 `false &&` 禁用；
- `VersionHistoryPanel` 已实现，但 `versionHistoryOpen` 没有设置为 `true` 的入口；
- `NoteMetadataControls`、`AttachmentPanel`、`NoteRelationsPanel` 组件没有接入 `NoteEditor`。

这些能力不进入 V9 默认稿。是否恢复入口属于单独产品决定，不能由视觉设计自行添加。

### V8 中必须删除的虚构内容

- 顶部“正文 / 字数 / 阅读时间”状态栏；
- 大纲、附件、历史三个常驻图标；
- 当前编辑器没有接入的标签行；
- “已自动保存”状态；
- 虚构的编辑器面包屑与分享、收藏按钮。

## 5. AI 助手

来源：`src/components/AIPanel.tsx`

### 当前可达功能

- 当前对话标题；
- 展开历史对话菜单；
- 搜索、切换、新建、重命名和删除对话；
- 收起 AI 助手；
- 用户和 AI 消息；
- 用户消息附带的选中文字，可展开/收起；
- AI 回答中的真实引用，按笔记聚合并可跳转原文；
- AI 回答后针对所选原文发起“补充理解”；
- AI 草稿卡片及继续打开草稿；
- 未在底部时“回到底部”；
- 输入区引用当前笔记，支持移除；
- 输入区引用选中文字，支持移除；
- 输入模式只有“对话”和“全库搜索”；
- 发送、停止生成；
- 修改预览或草稿检查点的确认入口。

### 代码存在但当前没有可见入口

- 语音识别逻辑存在，但当前 JSX 没有语音按钮；
- Agent 当前/近期任务面板被 `false &&` 禁用。

### V8 中必须删除的虚构内容

- “问答 / 润色 / 行动”三段模式；
- “正在阅读全文”状态条；
- “上下文已就绪”“核心观点已提取”等常驻执行步骤；
- 与真实消息结构不同的建议卡和固定三条行动建议；
- 并不存在的独立麦克风入口。

## 6. AI 修改预览

来源：`src/components/EditPreviewWorkspace.tsx`

- 没有待确认修改时返回笔记；
- 有预览时显示目标类型、说明“应用后才改变正式笔记”；
- 取消、应用修改；
- 错误状态；
- 修改摘要；
- 行级 Diff / 全文预览切换；
- 新增、删除行数和长文精简提示；
- 原文、修改后内容；
- 撤销上次调整；
- 选择并恢复历史预览版本；
- 输入新要求继续调整预览。

设计规则：该模式继续保持专注工作区，不把目录和 AI 面板强行塞回同一画面。

## 7. AI 笔记草稿工作台

来源：`src/components/AIDraftWorkspace.tsx`

- 覆盖式草稿工作台，关闭后保留进度并可从对话继续打开；
- 草稿标题、目录管理、全文要求；
- 全部生成、停止生成、保存为笔记、放弃草稿；
- 全文生成进度；
- 左侧章节目录及章节状态；
- 单章生成、重新生成、编辑/保存修改、确认；
- 对单章输入要求并让 AI 修改；
- 所有章节完成后完成草稿；
- 目录管理：新增、改名、上下移动、删除、恢复、按要求重新规划；
- 保存为笔记：确认标题和保存位置。

设计规则：V9 主工作台只保留真实的草稿卡入口；草稿工作台应作为单独画面继续设计，不缩成右栏中的虚构功能。

## 8. 全库搜索

来源：`src/components/LibrarySearchDialog.tsx`

- 搜索标题、章节和正文；
- 范围：全部、标题、正文；
- 中文输入法组合态与防抖等待；
- 加载、失败重试、无结果、结果列表；
- 结果按笔记聚合，显示位置、更新时间、匹配标签和命中片段；
- 键盘上下选择、Enter 打开；
- 手机端全屏。

## 9. V9 首张主稿的内容边界

V9 首张图只显示一个真实可达状态：

1. 桌面端目录展开；
2. 已选择一篇包含多个章节的笔记；
3. 用户已打开 AI 助手；
4. AI 处于“对话”模式；
5. 当前笔记和一段已加入对话的选中文字作为真实上下文；
6. AI 回答包含可跳转的真实引用；
7. 编辑器显示真实的选区工具栏和章节快速导航。

不在同一张图中堆入设置、回收站、搜索、草稿和修改预览弹层；这些后续按真实入口分别出状态稿。
