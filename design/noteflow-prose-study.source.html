Go 语言 · GORM 学习笔记

4.4 删（Delete）

db.Delete(&u, 1)                     // 删 id=1
db.Where("age < ?", 10).Delete(&User{})  // 按条件删

软删除：模型里加 gorm.DeletedAt 字段，GORM 就不会真删，只是把 deleted_at 写上时间。

type User struct {
  ID        uint
  Name      string
  DeletedAt gorm.DeletedAt `gorm:"index"` // 软删除魔法字段
}

查询时会自动过滤被软删除的记录；想看全部用 db.Unscoped().Find(&list)。

5.4 预加载（Preload）：避免 N+1 查询

var users []User
db.Preload("Posts").Find(&users)
// 等于先查 users，再一次性把所有 Posts 都查出来填进去
💡

人话：没有 Preload，你循环 100 个用户就要查 100 次文章（N+1 问题）；有了 Preload，只查 2 次。
