# NoteFlow 工作台优化候选 · 2026-10-14

## 范围与批准状态

用户询问整体前端优化并表示大优化也可以；在「先看完整工作台几种状态，认可后分模块替换」的建议后授权开始。本轮落实该方案的预览阶段，不修改 src、server、正式笔记、账号、保存和模型流程。该候选不恢复已退回 V11，也不代表整页方案获批。

候选包括知识库并排、专注正文与 AI 协作三种完整状态。沿用当前书本 / 文件 / 账号图标、知识库无篇数标题、原功能语义和正文多色代码 / 红色行内代码 / 薄荷提示；提出统一顶部导航、安静的保存状态与面板动作、同套控件比例。

## 可以探索的变化

- 宽度足够时知识库与正文并排；同时展示 AI 时保留正文最小阅读空间。预览低于 940px 打开另一侧会收起前一侧，低于 700px 知识库或 AI 按顺序展开，不盖住正文。这些阈值仅供评审，正式产品应按实际内容宽度和用户设置实现，不能照搬为已验证生产断点。
- 右侧本文目录按章节组呈现，初始收起，通过正文标题旁目录入口展开；选择章节、折叠组内容可操作。预览是切换合成内容，不是原编辑器滚动定位或随滚动更新章节的实现。
- 保留彩色语法，但不是给示例手写颜色 span：打包项目已有 highlight.js 11.11.2 的 core / Go / Bash / Python / JavaScript 语法引擎，所有示例均以原始代码输入后解析，复制原文。保留 BSD-3-Clause 授权文件与源稿内授权说明。
- 示例笔记切换、知识库筛选、面板开合与复制可使用；聊天发送仅提示是预览，不调用 AI、写入账号或持久化输入文字。示例笔记不是用户真实数据。
- 可调整正文留白、正文最大宽度及知识库宽度；没有新增套餐、用量、登录、统计或其他虚构业务能力。

## 验证与限制

使用 visualize 自带 render.py 的独立 iframe 外壳及全新 headless Edge；1024 / 736 / 320px 检查三种状态、原生轮播与章节 / 组操作、键盘 Enter 目录入口、面板开关不丢未发送草稿、笔记切换 / 筛选、Go 和 Bash 原文复制、语法颜色、正文 / 工作台横向边界及深色通过。复制改为内存替身，无系统剪贴板写入；只放行本机 8197 预览，宿主 Lucide / Floating UI 资源由本地同库副本履行，其余请求阻断，pageerror 与未允许请求均为空。离线库副本为 1.8.0，不宣称与宿主 CDN 所标的 Lucide 1.17.0 / Floating UI 1.7.4 完全相同版本。

验证命令（模块 / 浏览器按本机环境配置）：

```sh
python3 /path/to/visualize/scripts/render.py /absolute/path/noteflow-workbench-proposal.html --serve --port 8197
NOTEFLOW_PLAYWRIGHT_MODULE=/path/to/playwright NOTEFLOW_BROWSER_EXECUTABLE=/path/to/browser node scripts/workbench-proposal-browser-test.mjs
```

测试迭代：首次外壳命令错误地同时给 destination 与 --serve，随后端口启动受沙箱限制，经批准正常启动独立预览。回流重建节点及外层轮播按钮落入产品 click handler 的问题，分别采用递增 revision / 不重建相同状态和根节点归属检查修正；沿用 DEV-10 的原型状态口径。测试曾在外层 1000px 高度 iframe 内原生 click 未交付到根监听器，扩大 QA 外层到 2600px 后原断言通过，没有以 DOM click 或强制点击替代，沿用 DEV-14 的完整取图 / 嵌套视口边界。初次窄屏同时打开左右面板时知识库入口虽切换状态但内容仍被自动收起，已在本稿按最后打开面板更新实际状态 / aria-pressed。以上均是候选 / 夹具问题，不冒充正式产品故障或生产修复。

桌面 AI 状态、窄屏知识库及深色整页图片已人工核对。补测键盘提示时本地 Floating UI UMD 缺少 core 全局依赖，改为完整离线 bundle；隐藏后的对话输入不再用仅匹配可见元素的角色选择器检查，夹具修正后草稿原值仍保留。这些不是正式业务应用的缺陷。此验证不包括实际 Tiptap 编辑、保存 / 撤销 / 选区、后端、真实 SSE、长文帧率、滚动章节跟随、真实移动键盘与最终审美。AI 286px 只是受内嵌预览宽度约束的候选值，不代表批准更换正式默认 500px。UI-02 / UI-05 / UI-07 / UI-17 / UI-31 均不因预览通过提高状态。
