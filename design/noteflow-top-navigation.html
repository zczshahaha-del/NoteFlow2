2. 变量、常量与基本数据类型

Go 是一门静态类型语言。变量的类型在编译时确定，让代码更清晰，也更容易维护。

2.1 变量的声明与初始化

使用 var 声明变量，可以写出类型，也可以让编译器自动推断。

Go
var name string = "张成"
var age = 24 // 自动推断为 int

短变量声明：在函数内部，用 := 声明并初始化变量，写法更简洁。

Go
name := "张成"
age := 24
height := 180
先保证表达清楚，再选择更简洁的写法。代码是写给人读的。
