## 历史方案

| 版本 | 当前用途 | 不应如何使用 |
| --- | --- | --- |
| [V10 · 柔光工作台](noteflow-soft-focus-v10-notes.md) | 整页结构与功能边界参考 | 不再作为最新视觉候选 |
| V9 · 现有功能重排 | 历史功能边界对照；入口审计继续有效 | 不再作为最新整页视觉候选 |
| V8 · 精密柔滑工作台 | 用户此前认可的柔和材质与图标方向参考 | 不照搬其中被撤回的虚构入口 |
| V7 · 流体工作台 | 已否决的位图试验，保留反馈证据 | 不用于实现或排版基准 |
| V5–V6 | 视觉语言演进参考 | 不代替当前功能审计 |
| V4 · 真实工作台 | 早期组件映射与结构参考 | 不作为当前画风 |
| V1–V3 | 概念探索与纠偏记录 | 不作为产品需求或可实施方案 |

后续先确认 V11，再逐个模块改正式代码、测试、提交和推送。搜索、设置、回收站、草稿、修改预览等独立状态尚需沿用同一语言单独设计，不应全部堆进主画面。
