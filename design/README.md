2026-10-01 用户退回 V11：改动范围过大，设计者没有充分理解已有细节，不能作为实施基线。此前选择侧栏 A 和认可苹果式审美，不代表批准重排整页或改变操作习惯。正式页面与业务代码未被 V11 替换，不需要回退业务代码。

后续以当前真实页面为基线，一次只讨论一个区域，先保留功能、位置、顺序、信息密度及交互行为，仅提出清晰可对照的视觉变化。需要改变布局、可见性或行为时单独确认。
