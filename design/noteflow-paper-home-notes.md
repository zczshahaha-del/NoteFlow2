# NoteFlow 笔记归页登录预览

日期：2026-10-21。关联：AUTH-01。状态：用户初步认可故事方向；美学精修候选待评审。

## 反馈与改动

用户明确退回首稿：文案与笔记不贴切、出现「播放完整旅程」、动画虽然在动但没有故事。根因是用营销文案、阶段标签和独立演示入口解释场景，纸张本身缺少贯穿前后的身份与目的地。

本轮移除宣传标题、英文装饰、纸张上的诗意短句、故事进度与完整播放入口。表单仅保留登录 / 注册、邮箱 / 验证码、继续 / 登录和修改邮箱等必要文字。预览说明放在画面外，只说明示例数据与不发邮件。

新的连续动作：

1. 摊开的笔记本右页留有空位。带蓝色页签的一张纸从该处飞出，沿弧线放大并展开，纸面本身就是登录表单。
2. 聚焦和输入时，散落笔记向笔记本靠拢。纸张内容采用清单、图示和曲线，不编造用户笔记文字。
3. 点击继续，蓝色页签折成小纸飞机，飞出再返回；同一纸面进入验证码步骤。
4. 点击登录，表单内容收起为笔记图示，原纸页缩回笔记本右侧的空位，其他散页归拢，保留相同的蓝色页签作为前后识别标记。

开场自动进行，聚焦输入可立即结束开场。后续依附登录操作，不要求用户启动一段演示。交互仅在本地发生；示例邮箱 `note@example.com` 和演示码 `123456` 预填，以便直接评审。没有读取、发送、持久化真实用户内容。

## 初稿运行验证（精修前）

独立 Edge 临时浏览器运行隔离沙箱预览，网络请求全部拦截；宿主图标由本地 Lucide 包供给。本稿无业务网络调用。

- 1024 / 736 / 320px 无横向溢出；可见控件均位于画面内，按钮高度至少 44px。
- 自动开场完成；邮箱校验 / Enter、发送中返回及迟到回调取消、登录 / 注册切换、错误验证码 / 重试、登录后纸页归位、返回登录通过。
- 邮箱与验证码步骤的主按钮纵坐标稳定。
- 暂停时画布像素保持静止；系统减少动效时静态切换仍能完成操作。
- 深色及暂停状态下的主题切换检查通过，最终浏览器 `pageerror` 为 0。
- 新增七张浏览器截图，覆盖开场、桌面、手机、发送、归位过程、归位结果和深色。人工检查纸页、表单与笔记本关系及移动端可读性。

预览初版主按钮白字对比度测得约 4.30，已将按钮独立调深为 `#52758b`，最终正常态高于 4.5；纸张美术配色不受影响。暂停时主题切换另增加重绘，避免背景变化但画布保持旧色。均在本轮修正并复验，作为 AUTH-01 的局部设计验证记录，不新建同义问题。

源稿 JavaScript 语法和 Git 空白检查通过。本轮不涉及正式业务代码，因此未用业务构建代替预览验收。

## 同日：纸张材质、空间与表单比例精修

用户认为方向「差不多」，提出继续优化美观，并批准四项精修。视觉上的不足是主纸页边缘和材质偏硬、散页分布偏均匀、笔记本封面与主按钮偏重，视线不够集中。

- 主纸页从 368 × 422px 收至 352 × 402px，加入极浅纤维纹理、微弧纸边和柔和分层阴影；折角更自然，蓝色页签更纤细。
- 背景从八张散页减为五张，以不对称位置、大小、透明度和轻微模糊形成远近；光照改为宽而柔和的暖色光。
- 笔记本封面减薄，纸层、书脊和页面曲面更轻；保留右页空位与蓝色页签，维持故事中的辨识线索。
- 收紧标题、输入区和留白，主按钮改为浅蓝底配深色字。必要文字、自动开场、发送与归页流程保持原有设计。

精修后重新运行隔离 Edge 检查：1024 / 736 / 320px 的控件完整性、无横向溢出、44px 按钮、自动开场、邮箱 / 验证码校验与 Enter、发送取消、注册切换、纸页归位及返回登录均通过。邮箱和验证码步骤的主按钮位置保持稳定。浅蓝按钮正常态文字对比度约 5.70:1；暂停像素静止、暂停时切换主题和系统减少动效检查通过，浏览器 `pageerror` 为 0。七张截图已刷新，人工检查桌面、手机、深色及归页结果；本轮未使用真实邮件或笔记数据。

源稿 JavaScript 语法与 Git 空白检查通过。未修改正式业务代码，未以业务构建替代预览运行验收。精修前证据留在 Git 历史；当前文件与截图均为精修候选。

## 边界

- 故事感、视觉与节奏仍由用户评审，不能因为流程测试通过就标记 AUTH-01 已解决。
- 正式 LoginPage、密码登录 / 重设、认证后端、真实邮件与工作台均未修改。
- 最终笔记本为无真实数据的概念画面，不是实际登录结果。
- 实体触屏、读屏、低性能设备帧率与生产环境尚未验收。
- 首稿文件和截图保留，并明确标记为已退回。
