# NoteFlow 工作台 V6 · Silk-soft Precision

## 设计目标

V6 回应的是 V5 在细节上的不足：整体结构已经可用，但图标、控件轮廓、选中状态和阴影仍偏工具化、偏硬，缺少“柔滑、时尚、精致”的统一感。

本稿保留 NoteFlow 的真实三栏架构，只重新设计视觉细节。成品图为 `design/noteflow-workspace-v6.png`，1586 × 992 PNG。

## “柔滑”不是简单的大圆角

本稿把“柔滑”定义为五个可以实施的设计规则：

1. **连续曲率**：交互控件使用克制的 squircle/超椭圆轮廓，转角在进入圆弧前平滑过渡，避免普通 `border-radius` 带来的突然拐弯。
2. **柔和光学重量**：线条、文字和图标的粗细不过度跳变，默认态安静，激活态通过轻填充和色彩变化表达，不突然变粗。
3. **悬浮而不厚重**：浮层使用范围更宽、透明度更低的环境阴影，并增加极轻内高光；不使用硬黑阴影或低对比拟物阴影。
4. **色彩缓慢过渡**：珍珠白、云灰和雾蓝构成连续背景，只允许大面积环境色有近乎不可见的过渡；按钮不使用廉价渐变。
5. **有弹性的状态变化**：面板、选中行、输入框和 AI 步骤应采用柔和减速曲线，呈现“滑入、贴合、稳定”的感觉。

## 图标系统

- 统一使用 20 × 20 光学网格。
- 基础描边约 1.75px，圆形端点和圆形连接。
- 图形必须视觉居中，控制内部负空间一致，不能只按几何中心对齐。
- 默认态为暖石墨灰，不给每个图标增加底框。
- 激活态使用钴蓝描边与极浅蓝内填充，形成克制的双色状态。
- 完成状态允许从轮廓短暂过渡为轻填充，例如 AI 任务步骤和保存状态。
- 禁止混用不同笔画粗细、不同转角语言的图标，也不使用 Emoji、3D 图标或糖果质感。

## 视觉 Token 方向

| 类别 | V6 方向 |
| --- | --- |
| 主画布 | 珍珠象牙白，降低纯白的生硬感 |
| 左侧导航 | 带暖石色的云灰，弱化传统侧栏边界 |
| AI 面板 | 雾蓝与极浅青瓷蓝，保持清爽而不变成深色外挂区 |
| 文字 | 暖墨色主文字，中性灰蓝次文字 |
| 主动作 | 柔和矢车菊钴蓝，不使用电光蓝 |
| 微弱强调 | 极少量贝壳粉/杏色，只用于焦点和环境层次 |
| 成功状态 | 低饱和玉绿色 |
| 分隔方式 | 优先留白，必要时使用低对比发丝线或柔和曲线 |

## 关键区域处理

### 左侧知识库

- 搜索与新建保留，但轮廓和阴影更轻。
- 当前笔记使用滑入式浅蓝选中面与细长渐隐标记。
- 目录图标全部使用同一圆端线性家族。
- 回收站、设置和账号降低常驻对比，账号不显示邮箱。

### 中间编辑器

- 标题保持唯一，并降低过黑过粗的机械感。
- 正文、元信息和段落编号之间建立更平滑的字重节奏。
- 选区高亮使用柔和半透明蓝，工具栏通过小曲线指针与选区建立关系。
- 章节编号改为轻量圆形状态点，但不把正文变成卡片列表。

### AI 协作面板

- 模式切换、上下文、进度、答案和引用仍是一条连续信息流。
- 完成步骤使用轻填充图标，正在执行的步骤保持柔和外圈。
- 输入区形成轻微悬浮薄片，与面板底色分离但不过度浮夸。
- 引用标记和来源折叠行共享同一蓝色语义。

## 动效实现建议

- 主要过渡：180–260ms。
- 推荐减速曲线：`cubic-bezier(0.22, 1, 0.36, 1)`。
- 按压反馈：轻微缩放到 `0.98`，松开后柔和回弹，不使用夸张弹簧。
- 选中行：背景和标记同时滑入，位移控制在 4–8px。
- AI 步骤：轮廓到填充的过渡只发生一次，不持续闪烁。
- 输入焦点：边缘亮度和阴影范围缓慢增加，不突然出现粗描边。

## 实施边界

- V6 是整体画风与细节方向稿，不代表正式前端已经改造完成。
- 不改变目录、编辑器、AI、引用、任务、草稿和修改预览的产品架构。
- 图中小字主要用于验证信息层级；正式实现必须继续满足真实文本、键盘操作、对比度与响应式要求。
- 在用户确认方向前，不将该视觉方案批量应用到业务代码。
