# 统一账号入口与设置：正式实施记录

日期：2026-10-02。用户在局部稿后确认实施；不采用已退回的 V11，不重排整个工作台。

## 已落地

- 底部只有头像与实际用户名；没有可用昵称时沿用邮箱本地名，不显示完整邮箱。数字开头使用统一用户图形而非数字占位头像；紧凑侧栏只显示头像。
- 向上菜单为设置、回收站、退出登录；回收站数量来自真实状态，不再使用常驻蓝点。
- 设置为账号与安全、外观、AI 与记忆、数据管理四类。邮箱和设备在账号页展开，回收站在同一内容区切换，并可返回数据管理。
- 既有验证码、设备退出、主题、记忆编辑 / 确认 / 停用 / 删除、MD / ZIP / JSON 导入与两类导出、笔记恢复逻辑保留，不新增虚构功能。
- 删除仍属于笔记菜单。笔记明确可进回收站，文件夹保留子内容一起删除的原提醒，不声称文件夹可恢复。
- 局部作用域统一字体、1.6 细线图标、中性选中、圆角与阴影；菜单和模态框有 180ms 进退，分类轻淡入，reduced-motion 禁用动效。
- 共享 OverlayDialog 处理初始焦点、Tab 环绕、背景 inert、Escape / IME、关闭焦点恢复和退场期不可点击；仅替换本轮设置与删除确认。
