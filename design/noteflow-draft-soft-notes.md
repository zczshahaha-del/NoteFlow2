## 范围与基线

基于 `src/components/AIDraftWorkspace.tsx` 已有可见结构：上方标题与工具栏、进度条、左侧章节目录、右侧正文、下方章节操作与修改要求。没有新增业务功能，不改正式组件、模型、数据、运行服务或现有搜索改造。

“当前风格参考”是源码风格重绘，不是正式应用截图；两版都使用合成 Redis 示例。为了在对话中评审，桌面窗口收为 696px、目录 200px，原组件为最大 1240px / 桌面目录 282px；不是原页面像素级复刻，也不代表获准修改这些正式尺寸。两版使用相同的示例、区域顺序和评审尺寸。

窄屏稿仅为完整查看候选而重排为上下结构，工具栏保持顺序并换行。真实组件在 md 以下隐藏桌面工具栏，本稿不能当作已批准的手机入口方案；包括窄屏关闭按钮换行在内的移动端排布，正式实施前需另行评审。

## 本轮视觉变化

- 去掉候选外框及标题 / 目录 / 正文 / 底栏的重复分隔线，用间距区分层级。
- 中性选中行、轻量章节编号与完成标记；保留原有完成语义、未生成入口和 67% 示例进度。
- 工具与章节操作采用无框按钮，保存仍为主要动作，确认仍使用轻量成功色；不把所有按钮都做成黑色主按钮。
- 正文仍为主区域，修改要求保留在正文下方，采用单一柔和表面，保留原标签及按钮顺序。
- 统一 Lucide 图标、17px / 1.65 笔画（一般图标按钮 16px；已确认的关闭图标为 18px / 1.8）；不是 Apple 图标，不手绘路径。
- 全文要求从原入口向下展开，保存保持居中；候选展开 180ms / 减少动效静态回退，键盘焦点保留原生样式。

使用可视化技能来控制中文排版、图标和状态对照，没有用生成图片臆造产品功能。源稿与对话内稿相同。

## 功能对应与预览边界

| 原入口 / 状态 | 此稿处理 | 未进行的真实操作 |
| --- | --- | --- |
| 目录管理 | 保留原顶部入口，只宣布设计动作 | 不实现目录 CRUD、移动、恢复或 AI 重规划弹窗 |
| 全文要求 | 同入口展开；4000 字限制、空值 / 未改禁用、本地应用、Escape / 输入法保护 | 不触发真实章节重写；所输文字只留在此稿内存 |
| 全部生成 / 生成正文 | 保留顶部及未生成章节入口 | 不调用模型、生成或模拟实际进度变化 |
| 保存为笔记 | 保留顶部入口、居中弹窗、标题 / 保存位置、继续编辑 / 确认保存 | 位置为示例；不读取目录、不写入真实笔记 |
| 更多 / 放弃草稿 / 关闭 | 保留动作和顺序；更多菜单可展开 | 不删除草稿、不实现确认链或真实关闭生命周期 |
| 章节切换 | 两版同步本地选中，未生成章节显示生成入口 | 不读取真实草稿上下文 |
| 重新生成 / 编辑 / 确认 | 顺序保留；编辑与确认仅更新本稿，两版同步 | 不持久化章节；正式生成、停止、失败和批处理状态未模拟 |
| 告诉 AI 如何修改 / 按要求修改 | 原底部位置；空白禁用，编辑态收起 | 不修改真实正文，不模拟网络成功或失败 |

输入内容和编辑正文不写入宿主状态；仅保存带设计标识 / 版本的章节选择、确认状态及候选圆角 / 行高，外来或过期状态忽略。圆角 16–24px、行高 44–50px 仅作用候选，不改变参考版。

本稿不是完整业务原型：目录管理、忙碌 / 中止、失败、全稿完成、弃稿确认、正式 Modal 的背景 inert / 焦点约束等未覆盖。不要据此删改真实分支。示例首个正文小标题与章节名不同，不代表修复了真实重复 H1 问题 UI-08。

## 后续细节评审：修改框与关闭按钮

用户认可去掉框线，但明确不喜欢“告诉 AI 如何修改”右下角拖拽斜纹和右上角叉的简陋感。本轮仅细化该候选，不将反馈扩大为正式实施授权，不改变目录、工具 / 操作顺序、表面配色及已认可的去框线方向。

- 根因：原候选修改 textarea 保留 `resize:vertical`，斜纹是浏览器原生缩放手柄，不是新增业务按钮；关闭直接继承通用 16px 图标，没有单独定义底座和视觉重量。
- 候选修改框采用 `resize:none`，输入时自适应 52–104px，清空恢复 52px。超过上限使用原生文本滚动，保留完整文本，不增加展开按钮；手动拖拽仅在候选取消，参考版不改。长文、IME、手机键盘与真实工作区行为需正式实施前确认。
- 顶部关闭与两个嵌套弹层的图标关闭共用无框浅灰圆形底座，桌面点击区 34px、触屏 44px，中心 Lucide X 为 14px / 1.8，140ms 悬停色过渡和轻量按下反馈；不加原生 title、红色交通灯、标签或额外图标，不改关闭动作。
- 新增浏览器回归验证候选 resize 为 none、输入增高 / 上限滚动 / 清空复位 / 空值禁用、关闭圆角 50% / 无边框 / 图标尺寸 / 笔画 / 悬停变化 / 44px 触屏目标，原状态 / 焦点 / 居中 / 深色 / 减少动效检查继续通过，pageerror 为空。三张完整图已重新生成并人工检查，尺寸不变。
- 首次触屏检查发现新增关闭选择器比公共触屏尺寸规则更具体，导致目标仍为 34px；提高本稿 coarse 规则的局部匹配后实测 44×44。此设计稿层叠回归归 UI-05 / UI-17，不宣称修复正式全局 Token 或层叠问题。
- 本轮设计验证、test:editor-ui、check:dev-ports 通过；未改 src，因此未重复前端全量组件回归 / 构建。上节 42 组 / 10 项证据属于首版提交，不借作本轮新增行为的业务验证。

关闭外观与自适应行为仍待用户评审，正式界面和所有业务限制保持不变。随 `design: 精修草稿修改框与关闭控件细节`。

后续用户仍觉得叉怪，上一圆底没有通过审美验收。另行制作 `noteflow-close-study.*` 的实际尺寸 / 4× 放大小对照，候选取消常驻底座、增加叉的可见比例；随 `b33f683` 保留独立评审证据，原圆底仍只是历史过程稿。

## 关闭外观确认后：放回窗口候选

用户对独立对照回复“可以”后，仅将“无常驻底座”放回此草稿设计稿。不把单个按钮的认可扩大为整个正式窗口的实施授权，不改变其他布局、颜色、工具顺序、修改框或关闭语义。

- 顶部关闭、全文要求和保存弹窗的图标关闭均默认透明，18px / 1.8 Lucide X；悬停淡底、10px 圆角、140ms 色过渡，按下仅加深背景，没有缩放 / 旋转 / 弹跳。带文字的“继续编辑”按钮保持原样。
- 桌面点击区 34×34、触屏 44×44；不加 title 或自制焦点样式，保留原生键盘焦点。
- `verify-draft-soft.mjs` 新增透明底、10px 圆角、18px 图标、无变形、真实 Tab 焦点以及两处嵌套图标关闭一致性断言；736 / 320px、修改框增高 / 清空、保存居中、焦点返回、隐私状态、深色及减少动效回归通过，pageerror 为空。三张完整图重生成并人工检查，尺寸不变。
- 当前预览外壳还包含固定版本 Floating UI core 脚本，旧校验只允许 dom 脚本被阻止，首次回归在请求列表断言失败。根因是外壳依赖与测试预期不一致、请求出现受加载时序影响；将两条固定版本 URL 都识别为可选且已阻止的请求，仍禁止任意网络加载，不修改共享工具或产品代码。修正后通过；不是正式页面缺陷。
- `test:editor-ui`、`check:dev-ports` 通过；未修改 src，不重复全量业务回归或构建。隔离文件预览不访问受限应用、用户会话或 AI。

随 `design: 将确认的无底座关闭按钮放回草稿候选`。使用交互设计预览来核对按钮在窗口中的比例及嵌套一致性，没有扩展业务功能。
