## 改动与保留

- 表面最大 610px、18px 圆角、无常规外描边、中性选中、轻阴影；输入 16px、名称 14px / 500、摘要 13px、辅助 11–12px，图标 17px / 1.65，关闭 15px。
- 初始只留帮助，结果、空态及错误态按内容增长；输入区固定锚点，内容向下展开，结果区单独滚动。桌面上距 14dvh（24–160px），320px 布局上距 16px，两侧 12px；不再手机全屏大空框。
- 删除分隔线、范围外框、文件图标框、命中标签胶囊与结果横线。保留路径 / 原章节、更新时间、摘要高亮、额外命中数和原结果顺序；长名称换行、摘要仍两行，不虚构标题或日期。
- 210ms 高度过渡、180ms 进入、130ms 退出；关闭立即 inert / aria-hidden / 点击阻断，淡出内容保持，快速重开取消卸载；reduced-motion 静态回退，强制色保留边界 / 选中 / 焦点。
- 输入使用聚焦浅底与键盘底线，不叠加内部矩形焦点框；其他按钮保留明确键盘轮廓。触屏关闭 / 清空 / 范围 / 重试至少 44px，输入 16px。
- 保留全部 / 标题 / 正文、340ms 防抖、literal、20 条上限、请求序列、AbortController、IME、错误消息 / 重新搜索、按笔记归并、↑ ↓ / Enter 与原 `onSelect(primary)` + 关闭。
- 加载 / 输入等待 / IME 只播报一条；结果统计只在当前请求完成后显示。保留焦点环绕与返回，并让背景失活；正式页面没有评审标本标题、点阵、Tweak 或合成数据。
- 补输入法鼠标关闭后快速重开分支：失焦可能没有 compositionend，重开时取消未确认草稿、保留上次已确认查询，避免残留 IME 锁阻止 Escape；对应生产组件回归通过。

## 测试与实施迭代

前五次组件测试出现已记录 DEV-18 的退出码 137，未输出断言栈；可选 `NOTEFLOW_TEST_TRACE=1` 阶段 / RSS 诊断定位到已加载 harness 后的目录回归，采样约 200–320MiB 不构成退出原因证明。复核确认目录旧测试仍要求 Escape 后立即卸载，和新增退出动效不一致；改为先检查 inert 属性、等待 160ms 再检查不存在，并用布尔断言避免输出整个 DOM。JSDOM 未实现 inert 的属性反射，后续断言从 property 改为 hasAttribute；背景原状态仍原样恢复。最终回归通过，不宣称 137 底层根因已根治。

首次离线手机检查的标本漏了 viewport meta，浏览器布局按宽屏计算，补齐与正式 index.html 一致的 meta 后重测。随后确认触屏范围按钮仍为 32px：`:where` 的低优先级无法覆盖基础类的 min-height；改为同级具体选择器，最终实测至少 44px。人工检查发现聚焦输入出现重复矩形框，改为局部键盘底线，并保留强制色轮廓。这些是本轮测试 / 实施迭代，沿用 DEV-18 与 UI-02 / UI-05 / UI-10 / UI-17，不新增同义条目。
