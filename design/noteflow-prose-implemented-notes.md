## 后续：共享自动语法高亮（2026-10-11）

这次是独立的功能修复，不是再次修改配色或给示例写入彩色内容。`src/editor/codeHighlight.ts` 统一语法注册、语言别名 / 自动判定和 AST → UTF-16 token 范围；所有真实代码块的 NodeView 和装饰插件都调用同一解析器。选用 [Lowlight](https://github.com/wooorm/lowlight) 的语法树接口和 [Highlight.js](https://highlightjs.readthedocs.io/en/latest/api.html) 的语法，固定 Lowlight 3.3.0 与其兼容的 Highlight.js 11.11.2，依赖去重；只显式导入支持的语法，不加载全语言集。函数调用与运算符在未标记空隙补充现有 token 分类，保持原浅色 / 深色 CSS，不覆盖语法树的字符串与注释。

新建默认自动模式；粘贴 / 编辑重新解析当前内容，未标语言的 Markdown 和 HTML 重开也保持自动。菜单增加「自动识别」供手动选择后恢复；明确 Plain Text 时不染色，指定语言时尊重选择，未知标记按内容回退而非一律黑色。原文 / 手动语言持久化，推测结果和 token 装饰不进入笔记；没有 schema 或数据库迁移。不可变节点 / 文档 WeakMap 缓存避免移动光标或编辑其他段落时重复解析所有代码，也不长期保留旧笔记文本。

`test:code-highlight` 覆盖 21 个全新代码块粘贴 / 保存重开夹具及手动选项、未知语言、源代码保护、未完成输入、重新识别、撤销和缓存。`test:prose-ui` 在实际 NoteEditor 三种宽度中补真实键盘建空块、浏览器 DOM paste、继续输入、内存复制、原生语言切换及切换笔记重开；不注入 token、彩色 HTML 或访问原笔记 / 系统剪贴板。原生产样式、对比度、宽度、滚动和作用域回退检查仍保留。文档上方的已提交图片属于前一轮外观标本，不替代本轮新建流程的运行证据。

限制：语言自动识别不是确定性的编译器判断，短片段 / 混合代码 / 未支持语言仍可能需要手动指定；候选判定只采前 12000 字符，但最终高亮解析整块。新增语法有首次加载成本，NoteEditor chunk 压缩大小较原版约增加 28KB，主入口仍保持懒加载；毫秒级 400 行合成测量不是任意超长代码性能保证。实体输入法、真实剪贴板、Safari / Firefox 及用户原代码块仍待验收。
