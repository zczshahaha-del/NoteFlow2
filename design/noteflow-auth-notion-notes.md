# 认证入口 · Notion 风格正式实施

日期：2026-10-09。用户调研实页后明确选择 Notion 风格。本轮只改 NoteFlow 认证页面的视觉和分步呈现，不修改后端、工作台、账号、笔记或邮件配置。

## 参考与范围

参考 [Notion 公开登录页](https://app.notion.com/login) 的居中品牌 / 标题、邮箱 + 继续和轻量注册入口；保留 NoteFlow 品牌与之前确认的柔和蓝 #52769A，不使用 Notion 标识、宣传内容或社交登录。公开首屏不是 Notion 的完整认证规则证据，不照图推断其自动注册行为。

用户反馈的根因是：A 版把后台必须隔离的验证码用途，生硬变成了同一首屏的大号登录 / 注册切换栏与重复字段。新入口降低视觉重复，不删除注册，也不改为未经确认的自动建号。AUTH-01 / AUTH-03 在问题汇总中更新，未新增同义条目。

## 正式页面与步骤

- 首屏：品牌居中、标题与当前登录 / 注册文案、一个邮箱输入、“继续”；登录页保留次级密码入口，底部文字进入注册。
- 验证：同一输入位置切换为验证码，下方保留目标邮箱 / 修改、重发倒计时及返回入口。注册的主操作明确叫“创建账号”，只在有效注册验证码后调用既有 register。
- 密码：已有邮箱密码登录、显隐、大写锁定及忘记密码保留。重设先验证邮箱，第二步输入验证码与新密码，成功回到密码登录并聚焦。
- 布局：最大宽 360px；320px 留两侧 24px，表单 272px。输入与主按钮 44px / 8px 圆角，输入 16px；文字按钮与显隐至少 44px 命中。字段去掉装饰图标与常驻箭头，保留必要显隐 / 忙碌图标。
- 手感：160ms 字段淡入、短颜色 / 按下反馈，不用大幅弹跳；尊重 reduced-motion。标题和主轴稳定，邮箱切验证码时主按钮不位移；重设第二步按必要字段自然展开。
- 等待 / 失败：反馈在按钮下方的固定 44px 区域，长错误可滚动，不推动操作目标；失败保留输入。取消只是停止客户端等待，不假称撤回已发邮件。返回 / 目的切换不能绕过已启动的邮箱 / 目的冷却；切换、取消和编辑忽略迟到响应。

接口仍为既有 login / register purpose、验证码登录、验证后注册及密码重设。没有新账号存在性探测，也没有合并验证码用途、改会话 / 安全认领或添加数据库字段。前端冷却仍为保守 60 秒，后端可配置间隔的差异未在本轮解决。

## 验收边界

后端 / 账号安全规则未改变。真实 SMTP / Webhook、生产、PostgreSQL 并发 / 行锁、账号与笔记迁移、用户当前实屏、手机输入法 / 键盘 / 触屏、读屏和最终审美未验收。隔离 Cookie / SQL 与前端响应替身分别通过，不等于真实邮件贯通通过；AUTH-01 保持部分解决，AUTH-02 / AUTH-04 / SEC-02 的既有未完成项保留。

Node DEP0205、Python utcnow 弃用警告未修复。旧 A 版截图 / 设计源稿保留历史，不当作本轮当前外观。关联提交主题：`feat: 按 Notion 调整邮箱优先登录界面`。
