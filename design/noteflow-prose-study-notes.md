# 正文局部对照：图片参考与局部精修

开始：2026-10-10；继续与验证：2026-10-11，中国时间。

## 范围与评审边界

用户明确担心直接改正式页面不满意，随后同意先看独立预览。本轮仅设计，不把「可以呀 / 继续」解释为实施批准。没有改 src、server、配置、模型、账号或笔记；没有访问原浏览器会话、剪贴板或发起付费请求。此前 noteflow-reading-flow 整页稿仍为不采用。

两版逐字使用所给 GORM 截图中完整可见的「4.4 删除」及「5.4 预加载」片段，不重建被截断的事务代码，不假称整篇原笔记。新增顶部样例名称用于识别。名为「图片参考」的版式是根据附件重绘，不是当前 NoteFlow 的实屏，也不是像素级复制 Notion。

预览由可视化技能的局部稿与宿主轮播组织，精确排版依靠 HTML/CSS；多色代码使用这几段固定语法 span，不是生产高亮器实现。没有模拟复制、保存、编辑或聊天功能。

## 保留与微调

- 普通正文、标题仍为深灰；关键词蓝、字符串 / 类型绿、函数玫红、数字洋红、注释蓝灰，标点辅助分层。颜色不用于随意染整段正文。
- 行内代码为小块轻灰底红字；代码暖灰底、12px 圆角；提示块为薄荷绿，和正文同轴，没有厚边框或叠加阴影。
- 候选正文 16px / 1.8，标题层级 27 / 20px，代码 13.5px / 1.7、上下内边距 22px；图片参考的段落 / 章节间距及代码内边距略宽松。局部精修只收紧重复空隙，不把各块变成统一灰盒。
- 最大纸面 704px，736px 默认内容视口，480px 以下缩小外边距；两版阶段高度按较高内容测量，避免 handler 切换时底部导航跳动。
- 候选默认代码换行，参考保留行结构及局部薄滚动条。换行是设计选项，不意味着已批准正式编辑器改变代码行为。
- 可选宿主 Tweak 仅绑定候选字号 15–17px、行距 1.6–1.95、代码上下留白 18–28px、换行；缺失时静态首屏可读。只保存带设计身份与递增版本的设计参数，不保存内容、输入或敏感信息。
- 没有新增动画，减少动效样式检查只证明可读，不证明编辑、面板、真实 SSE 或总体流畅性已改善。
