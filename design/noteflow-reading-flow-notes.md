# NoteFlow 正文与连贯布局预览

日期：2026-10-10，中国时间。

## 评审结论：退回，不采用

用户明确反馈本稿不如原页面，正文失去了原有彩色层次。根因是候选稿过度使用中性色，并用示例正文代替原有内容；少量蓝色提示和代码配色不足以呈现用户认可的彩色高亮、提示块与语法层次。“统一协调”不能被解释为把正文灰化。

本稿保留为历史评审记录，不作为正式页面实施基线。本次反馈仅更新说明与问题状态，没有改动设计源码、正式页面或真实笔记。后续如获授权，应以原页面及其正文配色为底稿，保留已有彩色层次，再评审阅读比例、间距和过渡，不擅自重画正文或替换内容。证据为 2026-10-10 用户明确退回反馈；下述离线技术验证仍是历史证据，不代表审美验收通过。

## 七张正文参考的进一步澄清

用户随后提供七张 GORM / Git 笔记截图，要求仔细学习。它们澄清了上次反馈中的“彩色”：不是把普通段落改成多色，而是让代码语法、行内代码和提示容器有清楚、协调的色彩分工。以下仅为对所给截图的观察与后续评审约束，不是对当前正式页面的缺陷测量，也不构成新设计或实施授权。

- 正文与标题保持稳定的深灰；标题通过字号、字重及章前间距分级，关键概念局部加粗，不给每段另加卡片。截图经过裁剪与缩放，不从像素大小推定实际字号。
- 代码块使用接近白色的暖灰底、适度圆角和统一内边距，没有醒目的外框或厚阴影。等宽代码中的蓝色关键字、绿色字符串 / 部分类型、玫红方法名、紫红数字及蓝灰注释形成层次；具体 token 映射仍应服从语言语法，不手工按单词涂色。
- 行内代码是轻灰小底色配红色文字，紧贴句子且保留自然基线与换行，不变成大徽章。输出块与代码块属于同一套表面，但纯文本输出不应为了复刻截图而套错误的语言高亮。
- 提示块既有淡蓝，也有浅黄与薄荷绿；色彩主要在低饱和背景，正文仍深色。小图标与局部加粗帮助识别内容，不把全部提示统一刷蓝，也不只靠颜色表达含义。
- 标题、正文、列表、代码及提示块在同一内容轴上衔接；章间距离大于段间，薄分隔线用于少数章节边界，不把“减少框线”误作删除所有分隔。目录通过缩进与较弱文字分层，不机械复制截图中的长目录和大片空白。
- 截图中的代码操作区是小而轻的局部控件，不应扩大或常驻抢眼。是否悬停 / 聚焦显现及触屏入口需另做交互验证；不能从静态图宣称动效、滚动或真实 SSE 已经流畅。

处理与状态：将上述分工补入既有正文退回记录，保留原页面和原稿文件；候选审美仍未通过，UI-06 / UI-17 / UI-20 与真实流畅性状态不提高。本轮仅核对截图并检查文档差异，没有新的页面运行或视觉候选验收。

## 范围与依据

用户提供 Notion 录屏，进一步明确重点不是选中文字工具条，而是正文阅读、流畅性和整体美观统一，并同意先看同一篇正文的整页交互预览。

本轮仅新增设计片段、独立预览和离线验证脚本；未修改 src、server、模型、真实笔记、账号或原浏览器标签。历史 V11 仍不是实施基线，本轮也不构成正式页面或功能重排授权。

## 预览内容

- 同一篇示例笔记包含标题、段落、列表、代码、提示和引用，校准同一内容轴与阅读节奏。
- 正文候选首选宽度 650px、15.5px 字号、1.85 行距；控件使用协调的中性层次，强调色保留柔和蓝。
- 默认阅读、目录展开、AI 展开在同一页面切换；顶部触发位置稳定，正文不通过换字号适应面板。
- 目录 208px、折叠轨 52px、AI 292px，仅为 1024px 对话内评审尺寸。820px 以下用局部覆盖层，不能代替正式应用既有 1280px 策略的产品确认。
- 沿用已存在的目录、当前笔记引用、对话 / 全库搜索与停止语义；本稿没有模拟完整编辑、设置、草稿、删除、搜索后端或真实剪贴板。
- 回复完全在本地模拟，等待约 420ms 后按动画帧逐步出现；第一段正文取代“正在思考”，停止保留已显示内容，输入草稿独立保留。此流程不证明真实 SSE、模型首字或长历史性能已经解决。
- 窄屏与 coarse pointer 点击区至少 44px；减少动态效果时取消过渡并直接显示演示回复，保持可见的原生键盘焦点。
- 宿主状态仅保存设计身份、面板、笔记选择和 revision，不保存输入或对话文本；忽略过期回流，不在加载时保存。正文宽度 / 字号 / 行距 / 过渡可通过宿主设计控件局部比较。

## 验证

离线脚本：`design/verify-reading-flow.mjs`。先用 visualize 自带 render.py 重新生成 preview，再运行脚本；通过 NOTEFLOW_PLAYWRIGHT_MODULE 与 NOTEFLOW_BROWSER_EXECUTABLE 指定已有 Playwright / 浏览器，不新增项目依赖。脚本启动全新临时 headless 环境，所有外部请求阻断；宿主 Lucide 仅在测试中由已安装官方 lucide-react 生成同名图标替身，可选 Floating UI 请求返回空脚本，不能据此宣称宿主 tooltip / Tweak 实屏已验收。

1024 / 736 / 320px 内容宽度均实测，scrollWidth 等于对应宽度；目录 / AI 开合不改变正文字号和触发按钮 x。展开目录图标为 14px；320px 目录、AI、文件夹、笔记与发送按钮实测至少 44px。输入保留、IME Enter / Escape 保护、普通 Escape 关闭与焦点返回、停止后的文字 / 草稿保留、过期状态回流拒绝、逐步文字更新及模式切换通过。深色、减少动效、pageerror=0 通过；没有真实业务请求。

迭代边界：默认 Playwright 浏览器包不在本机，改用已有 Edge；受限启动 SIGABRT 后，经批准仅执行本稿离线检查，不读取原 profile 或改变浏览器安全参数。触屏模拟在鼠标操作后报告 coarse=false，因此增加窄屏 44px 兜底，不能代替实体触屏验证。初版 :where 命中规则被更具体基础选择器覆盖，改为同级 :is 并新增四类控件的几何断言，详见 DEV-23。图标尺寸沿用 DEV-15 的局部级联保护；状态版本沿用 DEV-10。短外层 iframe 截图曾截断尾部，沿用 DEV-14：只扩大 QA 外层视口，再取完整图，不禁用产品动画或用不完整图交付。

输出图片与结果保存在脚本创建的系统临时目录，复跑可重建；源码与对话片段 SHA-256 一致。脚本语法与 diff --check 通过。没有正式业务文件变动，因此不把既有构建 / 前后端测试借作本稿新证据。
