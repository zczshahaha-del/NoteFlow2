# 聊天面板精修预览 · 2026-10-15

用户在聊天审查后要求查看建议落地后的预览。源稿 `noteflow-chat-refinement.source.html` 用合成 GORM 笔记与对话展示完整工作台；聊天保留无框回答、浅灰用户气泡、彩色代码、轻量来源与复制时间。

本稿提供正常对话、多行输入、回复中断三种预览状态。输入容器在桌面标本中由 117px 随四行输入增至 158px，textarea 为 53 → 94px，上限 170px；范围菜单统一普通对话、当前笔记与整个知识库。回复更多菜单展示插入正文 / 保存为笔记的确认预览。重试在本稿仅切换示例状态，不发起真实请求；复制、来源跳转、新建与开合等入口均提示其预览含义，不操作真实笔记或剪贴板。

1024px 完整工作台、736px 正文与聊天、320px 单聊天布局均在独立 Edge 浏览器的受限 iframe 中检查，root scrollWidth 与 clientWidth 分别一致，状态切换、输入增高、范围选择、中断重试、更多菜单与确认预览通过，pageerror 为空。图标由已安装官方 Lucide 包离线适配，所有外部请求本地拦截；未连接用户后端、账号、模型和数据。正常态三宽度截图及中断态截图在本地临时目录人工检查，不提交图片。

源稿为评审用途。UI-34 / UI-35 仍未解决，UI-05 / UI-17 保持部分解决；它不证明跨会话草稿、真实网络失败恢复、产品键盘契约或流式性能已经实现。正式 src / server 文件未改。本轮不运行业务构建，验证范围仅为设计预览与 Git 差异检查。可单独回滚此设计提交。
