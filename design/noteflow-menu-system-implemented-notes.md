## 实施与保留

- `menu-ui.css` 为现有菜单提供作用域规则：14px / 400 字体、38px 基础行高、14px 外圆角、9px 行圆角、6px 外留白、11px 图文间距、17px / 1.65 菜单图标。去外描边、轻阴影和中性 hover；删除保留危险色。修正这些菜单的字号层叠，不改全局 reset。
- `DirectoryTree` 保留笔记六项顺序及全部回调，文件夹仍只有重命名 / 移动 / 置顶 / 删除，不增导出 / 收藏。新建笔记 / 文件夹仍使用原流程；不改目录行、顶部图标、顺序或收起形状。
- `NoteEditor` 只改变章节编号选项的表面及文字层级，编号偏好读写代码不变。
- `AIPanel` 保留历史搜索、日期分组、选择与行内重命名 / 删除，不增加操作弹窗。行内图标 15px 为光学例外；选中标记保留 13px。加入 focus-within / focus-visible 显现；coarse pointer 无 hover 时直接显现原操作并提供 44×44px 点击区。截断会话名原 title 保留，未新增原生提示；未扩改聊天、等待或删除确认对话框。
- `AppNav` 仅菜单表面复用同一规范，保留整行账号入口、真实昵称 / 数量、向上位置、宽度、无分隔线及原 180ms 进退 / 焦点逻辑。头像颜色与图形不改，不重构设置内部。
- 新共用 `SoftMenu` 管理其他四类菜单的 170ms 入场 / 130ms 退出，关闭后立即 inert / aria-hidden / 禁止指针并阻止残留内容点击，再卸载；快速重开清除旧定时器，reduced-motion 立即卸载。面板内 Escape 关闭并返回入口，输入法 Escape 不被新处理器截获；原外部点击和业务关闭逻辑保留。
