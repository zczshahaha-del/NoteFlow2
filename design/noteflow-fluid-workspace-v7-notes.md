# NoteFlow V7 · Fluid Editorial Workspace

## 用户偏好基线

V7 不再依赖“现代、好看、柔滑”这类容易产生歧义的形容词，而是基于用户明确选择的设计矩阵：

- 第一组 `BBC`：柔润时尚；柔软圆润、轻微悬浮并带弹性的按钮；允许整体布局与交互重构。
- 第二组 `CBB`：奶油白＋雾蓝；细线＋局部柔和填充图标；适中信息密度。

成品图：`design/noteflow-fluid-workspace-v7.png`，1586 × 992 PNG。

## 为什么 V6 仍显得传统

V6 统一了图标、圆角和阴影，但它仍然建立在三条等高竖向区域上。视觉细节变柔了，组件语法却仍是“侧栏—文档—聊天面板”，因此容易产生经过美化的 SaaS 后台感。

V7 的重点不是继续调色，而是改变功能层与内容层的关系：正文成为连续底层，导航和 AI 作为需要时滑入并贴合上下文的功能层。

## 新布局架构

### Flow Bar

- 顶部以一条轻量 Flow Bar 串联品牌、空间、路径、搜索、保存状态和全局操作。
- 不再让左、中、右各自拥有一套重复顶栏。
- 控件按任务顺序排列，使用留白分组，不依赖多个边框容器。

### Knowledge Layer

- 知识库从永久硬侧栏变成与细窄图标轨连接的滑入层。
- 搜索、新建、最近、收藏、全部笔记、目录树、回收站、设置和账号能力完整保留。
- 当前笔记使用滑入式选中面和局部填充图标；账号只显示“张成”，不展示邮箱。

### Continuous Editor Canvas

- 编辑器是整屏连续底层，而不是被左右边界夹住的纸张卡片。
- 标题、元信息、正文和选区保持单一阅读轴。
- 选择工具栏贴近选中文字，并与右侧 AI 协作层建立隐性对齐关系。

### Contextual AI Layer

- AI 不再是永久等高第三栏，而是位于内容之上的上下文协作层。
- 模式、当前笔记、执行进度、回答、引用和输入仍完整保留。
- 内部尽量依赖间距和色域分层，避免聊天气泡与卡片继续嵌套。
- 精修版减少了蓝色光晕、装饰图形和过大的圆角，使柔滑感保持成熟。

## 图标与按钮语言

- 图标采用 20 × 20 光学网格、圆端细线和局部浅色填充。
- 默认图标无容器；只有悬停、聚焦、选中或高价值动作才出现柔和承载面。
- 主按钮使用柔钴蓝 squircle，轻微内高光和低透明环境阴影。
- 次级动作默认无边框，悬停时才浮现背景。
- “加入对话”和发送按钮共享同一主动作语言。
- 不使用 Emoji、混杂线宽、厚重胶囊、荧光描边或糖果质感。

## 色彩与材质

| 层级 | 颜色/材质 |
| --- | --- |
| 内容底层 | 奶油珍珠白，提供温柔但清晰的阅读背景 |
| 功能层环境 | 极浅雾蓝，表示导航与 AI 的临时工作区域 |
| 主文字 | 暖墨色，避免纯黑的生硬感 |
| 次级文字 | 中性灰蓝，保持足够对比度 |
| 主动作 | 低饱和矢车菊钴蓝 |
| 成功状态 | 克制玉绿色 |
| 阴影 | 中性、宽而淡，只表达层级，不制造发光效果 |

## 对现有代码的映射

| V7 区域 | 可复用实现 | 后续改造方式 |
| --- | --- | --- |
| Flow Bar | `App.tsx`、编辑器头部操作、搜索入口 | 组合为统一顶栏，保留原事件和权限逻辑 |
| Knowledge Layer | `DirectoryTree.tsx`、`AppNav.tsx` | 不重写数据能力，只改变承载与展开方式 |
| Editor Canvas | `NoteEditor.tsx` | 保留 Tiptap、保存、附件、版本、关系和选区能力 |
| AI Layer | `AIPanel.tsx` | 保留模式、SSE、任务、引用、语音和会话，只重组呈现结构 |
| 响应式 | `ResizablePanel`、现有抽屉逻辑 | 宽屏为上下文层；中屏自动收起知识库；小屏继续使用全屏抽屉 |

## 动效方向

- Flow Bar：页面切换时保持稳定，路径和状态做局部柔和过渡。
- Knowledge Layer：从图标轨滑入并贴合，使用 220–280ms 柔和减速。
- AI Layer：根据选区或 AI 操作从右侧轻移入场，不使用大幅弹跳。
- 选中行：背景、图标填充和细标记同步滑入。
- AI 步骤：轮廓完成后变为浅填充，动画只执行一次。
- 按钮按压：约 `scale(0.98)`，松开时轻微回弹。

## 实施边界

- V7 是待确认的整体布局与视觉方向，正式业务代码尚未修改。
- 重构的是界面架构，不删除 NoteFlow 已有功能与数据流程。
- 图片中的小字主要用于视觉验收；代码实现仍必须满足真实文本、对比度、键盘操作和响应式要求。
- 用户确认方向后，应按 Flow Bar、知识库层、编辑器、AI 层、响应式和动效拆分提交，不一次性重写全部页面。
