## 两个候选

- **柔和留白**：14px 基础文字，38px 菜单行、14px 菜单圆角、9px 行圆角，图标与文字间距 11px。中性 hover，删除保留危险色，去除菜单外描边，用轻阴影区分表面。
- **紧凑轻盈**：34px 菜单行、11px 菜单圆角、7px 行圆角，间距 9px，阴影更轻。内容和顺序相同，可对照密度差异。
- 两者 coarse pointer 的有效按钮高度不少于 44px；字号 / 图标不因触屏变大。没有原生 title 提示，保留原生键盘焦点样式。
- 开合候选为 170ms 入场、130ms 退出；reduced-motion 停止动画。数值属于本稿候选，不是 Apple / Codex 官方参数。

第一张的左侧为按源码风格重绘的笔记操作参考，**不是正式页面截图，也不是当前像素级复刻**；原页面的字体层叠问题不在设计稿里复现。其他四个标本用于看统一后的协调性，不假称所有区域都提供了旧版截图。

1. Node 语法 / JSDOM 检查：两种候选完整生成；笔记菜单六个动作；置顶 / 收藏本地状态同步；52 个初始图标占位符；无数据 API、手绘图标 SVG / path 或错误转义。后续外壳生成轮播图标，实际共 55 个 SVG。

3. 交互：置顶 / 取消、菜单开合、章节编号同步、轮播切换通过；Escape 从新建菜单返回相应触发按钮，动作只播报预览边界。目录 / 导出 / 删除 / 退出等不执行真实业务。
