# NoteFlow「一张纸的旅行」登录动效预览

日期：2026-10-21。关联：AUTH-01 / AUTH-03。

## 需求与交付

用户希望登录具有全屏动画、互动与故事感，选择「一张纸的旅行」，本轮要求先看预览。新增独立概念稿，不替换正式 `LoginPage`、认证 API 或现有账号。

- 暖白与雾蓝的整页空间，远近纸张、卷曲纸角、阴影和细线纸流。
- 鼠标位置形成视差与近距离避让；点击空白产生一阵风。
- 邮箱输入增强纸流；继续后进入纸飞机送信，验证码步骤与主按钮保持位置。
- 演示校验通过后，纸张向中央聚拢成笔记，出现「故事，从这里继续」。
- 注册轻入口可切换文案，保持首屏只填邮箱；提供一键完整播放与重新体验。
- 支持暂停、系统减少动效、深色配色、视口外暂停；宿主可调风速与纸张数量。

此稿以验证视觉和故事节奏为目的。密码登录、找回密码、完整认证错误与冷却分支未在稿中展开；正式页面已有能力保留在原代码中。验证码 `123456` 是固定演示值，自动播放只使用 `hello@example.invalid`，不实际发邮件、不产生账号或登录会话。故事终点是独立概念画面，不是实际工作台转场。

## 运行验证

使用 Edge 独立临时浏览器资料目录加载上述沙箱预览。源稿没有业务网络请求；浏览器拦截全部外网请求，宿主 Lucide 由本地包供给，两个可选 floating-ui 资源被阻断，不影响本稿交互。

| 项目 | 结果 |
| --- | --- |
| 1024 / 736 / 320px | 文档宽度等于视口宽度，所有可见输入与按钮在画面内 |
| 按钮命中高度 | 三种宽度均至少 44px |
| 邮箱校验与发送 | 无效邮箱反馈、有效邮箱 Enter、进入验证码通过；主按钮纵坐标不变 |
| 取消等待 | 返回邮箱后，旧计时回调不会重新切回验证码 |
| 登录 / 注册 | 入口、标题和提交语义切换通过 |
| 完整旅程 | 三种宽度都完成发送 → 验证 → 聚拢 → 到达；重新体验清除演示输入 |
| 动效开关 | 暂停时画布像素保持一致；继续后画布重新变化 |
| 减少动效 | 系统偏好变化后停止连续动画，完整旅程以短暂静态状态切换完成 |
| 深色 | 三种宽度完成切换；桌面完整截图人工检查 |
| 浏览器错误 | 最终完整检查 `pageerror` 为 0 |

初次减少动效检查在媒体变化事件送达前读取按钮，修正检查时机后通过；未改产品逻辑来匹配断言。首次浏览器启动受本机沙箱限制，随后在授权的独立浏览器中完成上述检查。

视觉复核发现 320px 初稿的一张前景纸靠近正文文案，已单独调整移动端纸张锚点，重新运行 320px 交互检查和截图复核；桌面排布不受影响。本问题并入 AUTH-01 本轮设计记录，不新增同义问题。

源稿通过语法与 `git diff --check` 检查。此次只更改设计资产与说明，没有修改正式源码，未重跑业务构建或宣称真实认证通过。
