# NoteFlow 登录与注册 · A 流程设计

日期：2026-10-08。状态：**离线设计待评审，未替换正式登录页或后端认证**。

## 范围与依据

用户选择 A：注册必须验证邮箱，不强制设置密码；登录和注册明确分开。按本轮提供的 UI 偏好，使用清晰层级、协调圆角、中性主按钮、轻量图标、有限说明及自然过渡。不重新设计工作台，不增加手机号、社交登录、昵称步骤或展示不存在的产品能力。

- **柔和留白**：品牌在页面左上，开放背景承托居中表单，减少额外容器。
- **轻盈聚焦**：品牌与表单集中在单一轻量表面中，以位置和表面差异聚焦，而不是再叠一层卡片或装饰。

两版功能一致。重用当前 NoteFlow 品牌资产；日常图标使用同一套 Lucide，18px / 1.65 线宽，主按钮箭头 17px。产品表面保持实色和清晰边界，本轮不为追求玻璃感牺牲输入可读性。

## 功能映射与拟议行为

| 入口 | 所需输入 | 设计行为 / 实施边界 |
| --- | --- | --- |
| 验证码登录 | 邮箱、登录验证码 | 保留已有登录方式；拟改为仅登录，不再暗中自动注册。后端尚未改变。 |
| 密码登录 | 邮箱、密码 | 保留备用方式、显隐密码和忘记密码；无密码用户仍可使用验证码登录。 |
| 注册 | 邮箱、注册验证码 | 验证邮箱后创建账号，不要求注册密码。后续可选设置密码仍需正式实现及验收。 |
| 重设密码 | 邮箱、重设密码验证码、新密码 | 保留已有流程和返回入口，不增加独立认证产品。 |

注册、登录和重设密码必须使用不同目的的验证码。稿中切换目的或修改邮箱会清除旧验证码、发送反馈及当前等待，保留邮箱；密码登录草稿仅在当前页面内存中保留，不写入存储。错误保留输入。取消验证不解除同一目的的重发倒计时，编辑待验证内容取消旧预览结果。隐藏字段同时 disabled。

操作采用短促按下反馈，入口滑块约 230ms，内容约 180ms。尊重减少动效；错误与等待使用保留空间，主按钮不因反馈插入而跳动。进入重设密码后聚焦邮箱，返回后恢复对应入口焦点。无原生 title 悬浮框、粗光晕、额外工具栏或伪造的业务成功页。

## 文件与验证方法

- `.source.html`：可交互源稿；与本轮对话内稿一致。
- `.preview.html`：独立检查外壳，不是部署或正式登录入口。
- `-login / -register / -focus-login / -focus-register.png`：两版完整桌面标本。
- `-mobile / -focus-mobile / -dark / -focus-dark.png`：窄屏与深色标本。
- `verify-auth-entry.mjs`：只读取本地设计文件，网络默认阻断；图标库由已安装本地资源提供，不访问 5173、真实账号或邮件服务。

复现命令：配置本机 `NOTEFLOW_PLAYWRIGHT_MODULE`、`NOTEFLOW_BROWSER_EXECUTABLE`、`NOTEFLOW_LUCIDE_BUNDLE` 后运行 `node design/verify-auth-entry.mjs`。需要允许独立 headless 浏览器启动；默认受限环境首次启动 SIGABRT，经审批仅放行离线检查后继续，不改变浏览器安全策略或应用访问权限。

本轮检查覆盖两版的 1024 / 736 / 320px、横向边界、16px 输入文字、触屏按钮至少 44px、目的切换、倒计时、取消、等待中编辑、密码显隐、焦点返回、Enter、本地状态隐私、深色与减少动效。两版舞台均为 850px，按最长重设密码视图预留，不以业务页面必须固定此高度为结论。设计参数可调表单宽度及控件圆角，不保存邮箱、验证码或密码。最终脚本成功、error 为空；桌面 / 窄屏完整图片人工检查，无裁切。只属于离线设计验证。

## 设计阶段发现与修正

1. 沙箱未授予 allow-forms，原生 submit 不触发本地预览处理。只在稿中改用本地 button / Enter 处理，不放宽沙箱；新增 DEV-19。正式 React 页面不能照搬此限制。
2. 初稿取消验证会清除重发倒计时；已拆分“取消验证”和“清除目的”，仅输入邮箱 / 切换目的才重置。焦点转移和等待中编辑的旧结果也在稿中修正，归 AUTH-01 的设计细节。
3. 已知 DEV-15 的宿主图标尺寸覆盖再次出现；只加产品范围内的精确尺寸 / 线宽规则，不修改宿主或全局组件。
4. 宿主回流状态不能覆盖已开始操作的认证目的；仅初始恢复视图，操作后保留当前输入和任务。宿主保存仅含设计选择。
5. 首次深色图在 150ms 表面过渡结束前取图，出现中间灰色；检查改为等待稳定样式并断言输入表面为 rgb(40,45,53)，重新生成完整图，不拿过渡中间态冒充默认深色。窄屏基线也明确清空校验状态后取图。
6. 一次最终检查的阻断 URL 白名单断言失败，当时没有保存具体 URL。加入异常 URL 日志后，同一源稿完整复测通过且没有额外请求；不能据此确认原请求来源或声称根治。所有非本地文件 / 本地图标资源的请求始终被阻断，另记 DEV-20，保留下一次复现的诊断入口。
