Go 语言 GORM 学习笔记

· 已保存更新于 10 月 15 日
💡

一句话理解 GORM：把 Go 的 struct 当成数据库表来操作，用熟悉的代码完成增删改查。

1. 模型：把表写成 struct

先定义用户模型。字段 ID 默认作为主键，结构体名会映射为复数形式的表名。

Go
type User struct {
    ID   uint
    Name string
    Age  int
}

2. 创建与查询

创建记录后，可以通过主键或条件查出对应用户。查询结果会直接填入结构体。

Go
db.Create(&User{Name: "张三"})
db.First(&user, 1)
📌

先跑通一遍 CRUD，再学习关联查询、事务和钩子。

3. 关联查询

使用 Preload 预加载关联数据，避免循环中重复查询。

最近对话
帮我梳理这篇笔记的重点，顺便讲讲 Preload。

这篇笔记可以沿着 模型 → CRUD → 关联查询 这条线理解。

  1. 模型：用 struct 描述表和字段。
  2. CRUD：创建、读取、更新和删除记录。
  3. 关联：把用户、文章等数据联系起来。

Preload 解决什么问题？

先查用户，再一次取回关联文章，减少循环里反复查数据库的情况。

Go
var users []User
db.Preload("Posts").Find(&users)

记住：它预加载的是关联数据，字段名要和模型里的关联字段对应。
