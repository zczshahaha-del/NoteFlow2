# 对话等待与输入区局部修整 · 2026-10-02

## 方向与边界

落实用户对“正在生成”空框、粗光标及输入区视觉的反馈。采用低存在感状态、正文直接排版、中性表面与统一动作按钮，不照搬另一个产品的功能。

参考查阅 [OpenAI 的 Codex 官方公开介绍](https://openai.com/index/introducing-the-codex-app/) 与 [桌面应用公开文档](https://learn.chatgpt.com/docs/app)。这些资料未建立当前 Codex 等待动效的精确参数；原生界面读取被安全策略拒绝，本轮不绕过、不宣称测得 Codex 的具体字号、圆角或动画。

范围只有 AIPanel 对话正文、等待和输入区。目录、账号、历史列表、草稿工作区、修改预览、后端与模型配置不变，整页 UI 并未统一完成。

## 状态设计

- 等待首个正文：无框小圆点与“正在回复”，文字缓慢流光，拒绝大占位气泡、粗光标和跳动圆点。
- 正文输出：无外框 Markdown；下方保留小号真实活动状态，不伪造思考步骤或百分比。
- 完成 / 停止 / 失败：活动提示消失，保留 store 返回的正文或错误，不改现有状态机与停止回调。
- 用户消息：淡灰背景，不再叠加蓝色描边。
- 输入区：一个柔和外轮廓，内部无横线；模式选择、引用和圆形发送 / 停止统一中性颜色。

输入最小高度保留 158px。Enter 发送、Shift+Enter 换行、中文 IME、全库搜索、选中文字和当前笔记引用保持原规则。引用移除按钮始终可见，不依赖鼠标悬停；按钮保留可见的键盘焦点。等待提示使用 role=status，正文 busy 与状态提示分离，避免屏幕阅读器每个 token 都重复播报。reduced-motion 和 forced-colors 使用静态可读文字；深色单独提供局部变量。
