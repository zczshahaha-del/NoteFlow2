# NoteFlow V10 · 柔光工作台

> 日期：2026-10-01
>
> 状态：整页高保真候选，待用户评审；不是已上线的新 UI。
>
> 范围：主工作台的目录、正文、选区工具栏、章节导航、AI 对话与输入区。正式业务代码没有修改。

## 设计目标

用户希望重新设计整个页面，摆脱老式后台感，同时保留真实功能。本稿把已确认的侧栏 A「安静层级」扩展到整页，追求柔和、清晰、有阅读节奏的界面，不新增导航分类、统计、任务步骤或无意义装饰。

### 目录：安静而有层级

- “目录”与真实篇数分层，不再把标题、数量和所有工具挤在一行；
- 搜索显示为轻量入口按钮，仍打开原有搜索弹窗，不增加常驻内联搜索；
- “+”与搜索相邻，保留新建笔记 / 新建文件夹菜单；
- 使用用户截图中的“全栈开发”与五篇笔记名称；
- 普通笔记弱化重复文件图标，当前笔记保留图标、短色标与淡蓝背景；
- 文件夹使用细层级线，账号、回收站、设置继续留在底部。

### 正文：从控件堆叠转为阅读空间

- 不新增品牌顶栏，不给正文再套一张纸张卡片；
- 使用清晰的无衬线字，标题、章节标题、正文和元信息形成四级层次；
- 宽屏正文 16px / 1.9 行高，最大阅读宽度 706px；
- 选区才出现格式工具栏，所有 12 个现有操作保留；
- 表格使用轻横线、代码块使用淡底，减小技术内容的视觉噪声；
- 章节导航继续使用低干扰的右侧细轨，更多菜单只承载现有显示设置。

### AI：轻盈的协作区

- 面板使用淡蓝灰背景和柔和外轮廓，AI 回答不再逐段套卡片；
- 当前会话、历史入口、新建和收起保持在面板顶部；
- 引用按笔记与原文位置呈现，保留“补充理解”；
- 输入区把笔记 / 选区上下文、正文输入和动作拆成三个清晰层级；
- 只有现有的“对话 / 全库搜索”模式，没有新造的 Agent 状态或麦克风按钮；
- 图中已有一条未发送的示例输入，所以发送按钮显示可用；清空输入后禁用。

### 图标、控件与动效

- 同一套 Lucide，常规线宽 1.65，常规图标 18px，工具栏图标 14px；
- 蓝色集中用于当前选择、主要动作和引用，不把所有控件涂成蓝色；
- 控件 7–12px 圆角，AI 面板 21px，正文不加大面积阴影；
- 悬停和状态反馈 200–250ms，减速曲线 `cubic-bezier(.22, 1, .36, 1)`；
- 支持 `prefers-reduced-motion`，没有循环动效或装饰性闪烁；
- 保留原生键盘焦点，图标按钮有明确名称，主要操作不只依赖悬停。

## 对现有代码的映射

基线：[当前功能审计](noteflow-current-function-audit.md)。本轮复核的代码基线为 `fffa98d`，没有把“组件文件存在”当作“用户有入口”。

| 设计区域 | 现有来源 | 设计与现状的差别 |
| --- | --- | --- |
| 目录与底部入口 | `DirectoryTree.tsx`、`AppNav.tsx` | A 的视觉层级；宽屏建议 250px，当前代码为 260px |
| 正文、标题、时间 | `NoteEditor.tsx` | 新排版与阅读宽度；不新增保存状态、字数、标签或版本入口 |
| 选区工具栏 | `NoteEditor.tsx` | 保留全部已有动作，仅统一几何与图标 |
| 章节快速导航 | `NoteEditor.tsx` | 保留原功能，以细轨降低权重 |
| AI 消息、引用、上下文与模式 | `AIPanel.tsx` | 宽屏建议默认 434px，当前代码为 500px；正式可拖拽能力不能在实施时丢失 |
| 面板展开 / 收起 | `App.tsx` | 主图展示用户已打开 AI 的状态；专注图展示关闭后的已有启动入口 |
| 小屏目录与 AI | `App.tsx` | 设计原型窄屏使用覆盖抽屉，防止三栏硬挤；断点需在正式实现时回归实际工作流 |

上述宽度与间距是设计建议，不声称已写入 `src/`。右侧拖拽、真实编辑保存、真实搜索、对话管理、AI 生成与修改预览仍由正式产品实现。

## 示例数据与原型边界

- 五篇笔记名称及文件夹名称沿用用户截图；Redis 正文、时间、AI 对话、历史会话和引用位置是设计示例，不是读取或改写用户笔记；
- 原型可以检查展开 / 收起、菜单、章节编号、上下文移除 / 加入、输入禁用状态和标题筛选；
- 只有 Redis 填充示例正文；选择其他笔记不复制 Redis 内容去冒充实际文档；
- “发送”“补充理解”、新建、删除等动作只说明真实入口，不调用后端或写入数据；
- 搜索原型只筛选这五个示例标题，不能冒充正式全库搜索的正文检索、范围过滤或键盘结果导航；
- 会话历史只演示入口和筛选，不假装加载真实会话；
- 账号、回收站、设置、草稿和修改预览没有在本主稿中重新设计；
- 正式产品的深色模式、后端业务、保存、拖拽和端到端链路尚未验收。
