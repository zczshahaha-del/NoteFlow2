`dist/cloth.js`、`cloth.css`、`page.css` 及 `scripts/check-physics.cjs`。
没有接入包里的演示表单提交器、全局认证对象或认证配置。

2026-10-22 后续收敛：这是登录入口，不是动画演示。已删除重播 / 整理按钮、
大段宣传与重复提示，气泡不展示；仅保留品牌、功能标题、表单、必要状态和账号操作。
「继续」改为「获取验证码」，不再靠两行说明解释下一步。没有新增装饰功能。

2026-10-24 用户确认暖白 / 灰蓝概念图后，登录页接入与工作区相同的语义颜色和 UI 字体。
布面改浅白、纹理减弱，小人毛衣改灰蓝；轻灰圆角字段在聚焦时使用 1px 灰蓝边界。
参考和实施边界见 `design/noteflow-unified-visual-notes.md`，不是更换认证或动画引擎。

## 边界

- `LoginPage.tsx` 保留项目既有邮箱优先流程、验证码 / 密码登录、验证码注册、密码重置、
  取消 / 冷却、过期请求忽略、IME 和重复提交保护。沿用原有 props 与
  `services/auth.ts`；会话和 App 切换逻辑不变，无后端 / 账号 / 笔记数据修改。
- `cloth-login.js` 只画布料与小人，通过 `mountClothLogin(root)` 的
  `update(state)` 同步原生表单的内容，`destroy()` 负责卸载；
  可选的到位回调只在首次落位时触发，不承担认证动作。
  不发送认证请求，不保存输入，不接管密码显隐。输入是 React 管理的真实原生控件，
  Canvas 镜像只负责视觉，错误全文与可访问状态位于普通 DOM。
- 提供的两输入槽适配为「邮箱或验证码」与「可选密码」。
  2026-10-25 按用户纠正：验证码邮箱确认与“更换”收进卡片，重发 / 取消等待置于验证码框右侧，
  反馈位于主按钮上方；卡片外只保留切换方式、注册、找回密码等次级账号入口。
- 保留原步态 / 人物绘制、网格 / 约束求解、投影、拖拽载荷、回弹与输入防折叠恢复。
  拖拽时不额外绘制抓取位置圆环，布面两个固定扣与人物仍正常绘制。
  LAND 仍为 3.08 秒、END 为 5.05 秒（物理模拟时间）。
  `cloth-stage-layout.js` 独立计算真实视口宽度和居中锚点；更宽的入场路程增加步数，
  在不增加等待时长的前提下保持落脚和肢体约束，不通过单独放大小人或平移脚底伪造行走。
  立即聚焦输入或开启系统减少动效时直接放好布面；慢设备不承诺恒定墙钟耗时 / 帧率。

## 工程适配

- 全部 CSS 都限定在 `#cloth-character-login` 内，深色跟随项目的
  `.theme-dark`，不修改工作台、正文、代码语言框或复制控件。
- 小人、布面、原生输入与底部操作作为一个整体展示：宽度至少 1200px 且高度
  至少 800px 时放大至 1.10 倍，1600px / 900px 以上为 1.18 倍；手机、矮窗口
  保持基准尺寸，不单独修改人物比例、字号或内部间距。
  求解器继续使用逻辑尺寸；指针按实际显示比例反算，Canvas 后备像素同步实际
  显示尺寸，避免抓取错位或画面被低分辨率拉大。无 Canvas 降级表单不缩放。
  背景只添加静态柔光与低对比落地阴影，装饰层不可命中，强制颜色时关闭。
- 邮箱、验证码和密码使用批准预览里的轻灰圆角边界，焦点由外层显示 1px 灰蓝边界，
  失焦恢复浅灰；不在原生 input 上加内阴影或黑色 outline。输入字号仍 16px，字段外部尺寸、
  位置与编辑稳定区不变，文字左右留 12px（密码右侧仍为图标预留 42px）。按钮 / 链接保留键盘焦点，
  系统强制颜色模式使用 Highlight 实线后备，原生 required / 邮箱校验不变。
- 邮箱、验证码、密码始终由原生 input 独占文字、占位符、光标与选区，Canvas
  不再镜像任何输入内容。原生字色始终不透明，不按聚焦 / 自动填充切换绘字来源。
  未编辑时外层 `.cl-field` 随布面变换；进入编辑后两层都为 transform:none，
  使用已稳定布面区域的 left / top 固定坐标。pointerdown 捕获阶段只在切入编辑时
  恢复输入区域；同字段重复点击 / 拖选不再重启恢复，不拦截原生事件。
- 普通 / 自动填充共用主题墨色、16px 字号和布面底色；禁止用不透明输入内阴影遮盖 UA 底色。
  2026-10-24 用户复验及原 IAB 对照证明：仅去阴影 / 改文字背景裁剪不足以解决所有回填编辑问题，
  不能再把选区样式通过等同于原生编辑交接通过。
  自动填充仅裁剪 UA 背景（background-clip:text），原生字色不透明；明确设置浅深色选区背景，
  焦点边界归外层，不给原生输入附加阴影，以免裁剪时出现边线。保留 appearance:none。
  上层以原布面的 4×5px 线程重复补齐纹理，位于文字上方但不接收指针事件。
  该装饰位图不含输入内容，只在主题 / 尺寸更新时生成；不禁用 autocomplete / 密码遮蔽。
  强制颜色模式关闭纹理、使用系统 Field / FieldText、Highlight 焦点线与 Highlight / HighlightText 选区。
- 浏览器已回填但原生编辑仍卡住时，第一次主指针按下在默认光标定位前，将字段当前非空值
  原样写回同一原生 input，恢复编辑交接。邮箱、验证码、旧 / 新密码共用该处理；不先清空、
  不改 type、不模拟 Delete / input / change、不强设选区、不关闭 autocomplete、不保存凭据。
  非自动填充、空值和非主按钮直接跳过，正常编辑不反复赋值。原异常 IAB 同页只鼠标验证恢复，
  未按键 / 未重填；原生回填进入卡住状态的完整浏览器触发条件仍未稳定复现。
- 密码右侧改用 Eye / EyeOff 图标，44×44px 命中范围，保留显隐状态、悬停说明和读屏名称。
- 动画脚本仅在登录页挂载时动态加载，不进入工作台的初始脚本。
  每秒冷却计时不会唤醒静置动画；异步加载取消后不再挂载。
- 监听器使用稳定表单的事件委托，支持 React 替换邮箱 / 验证码 / 密码节点。
  pointercancel、lostpointercapture、窗口失焦、隐藏页面继续沿用原有释放处理。
- 卸载及初始化失败均移除监听器 / 观察器、取消 RAF / 点击恢复定时器并释放 GPU
  buffers / texture / shaders / program；不强制丢失 Canvas 上下文，兼容 StrictMode 重挂载。
- 无 WebGL 使用原 2D 渲染；没有 Canvas 或初始化失败则退回可用的原生表单，
  不阻止登录。演示控制入口已从产品 DOM 和事件绑定中移除，不是仅用 CSS 隐藏。
- 单列组合聚焦表单，辅助账号入口靠近布面下方。卡片内的邮箱确认在标题下方使用简略地址，
  无铅笔图标，以“更换”返回编辑；长域名单行省略，title 和验证码的可访问描述保留完整地址。
  重发 / 取消等待在验证码框右侧保留 84×44px 命中区，原生输入右侧预留 90px；
  320px 仍完整容纳六位数字与占位文字。按钮、输入位置及 448px 卡片不变。
  邮箱行与反馈的定位走既有布面适配器，入场到位前隐藏 / inert，拖拽时跟随布面；
  编辑期间同样使用固定无矩阵坐标，不参与原生输入绘字或阻止输入事件。每个操作仍至少 44px 高。
  发送中 / 发码成功 / 返回冷却步骤的重复说明只作 live region 播报，不占可见行；
  取消等待、业务错误全文、重设成功与大写锁定等重要反馈仍在卡片内主按钮上方按需显示，
  两行高度为 28px，长错误局部滚动，不挤动主按钮。网关的纯文本 / HTML / 空响应转换为中文连接提示，
  但已有 JSON 业务错误仍保留，即使没有正确声明 Content-Type；断网不裸露 Failed to fetch。
  不改请求取消、重发冷却、验证码用途或认证接口。
- 画布实际覆盖浏览器视口宽度，从屏幕右侧至少 32px 外开始，而非 740px 中栏外。
  垂直以「448px 卡片 + 12px 间距 + 44px 账号操作」整体居中，品牌不占用居中轴。
  使用居中的 664px 高绘制带，避免高窗口无意义地分配三张整屏 HiDPI 画布。
  观察窗口容器及绘制带尺寸，高度变化也会更新账号入口的纵向锚点。
  以上尺寸为逻辑坐标，较大窗口按同一展示比例一起居中，不加高物理网格。
- 加载阶段不闪现静态降级表单；正常入场时辅助区不可见、不可点击、inert 且
  aria-hidden，到 3.08 秒落位才淡入。聚焦跳过入场、减少动效和明确降级时立即可用，
  不强制用户等待；切换认证步骤不会重播或重新隐藏。

## 验证

- `npm run test:login-cloth`：原包物理断言直接读取适配后的正式脚本；
  对原包 27 个物理 / 绘制函数的 SHA-256 指纹作比较，防止静默改动步态、求解和恢复。
  同时读取正式布局函数，覆盖七宽度（316～1920px）肢体长度 / 着地、角色逻辑尺寸上限、
  初始卡片在真实屏幕外、居中、入场、两种大幅拖拽中聚焦、长时间回弹及无撕裂。
- `npm run test:auth-ui`：正式 LoginPage / auth 服务 / 构建 CSS，隔离 Edge 与合成 fetch；
  原有认证分支、错误 / 长错误 / 冷却 / 取消 / 重试 / IME / 重复提交、
  1920 / 1280 / 1024 / 736 / 320px、深色 / 减少动效 / 短视口 / 存储拒绝；
  另测 1920 / 1280 / 736 / 320px 正常动画、三种指针中断、入场聚焦、
  StrictMode 反复挂载与握持时卸载、观察器 / 监听器 / RAF 清零、静置停止渲染、
  无 Canvas 仍能提交认证。动画子集可用 `NOTEFLOW_AUTH_ANIMATION_ONLY=1`。
  拖拽时拦截正式 Canvas 的 arc 调用，确认仅保留固定扣、不再绘制抓取圆环，
  并在仍握持布面的状态截图核对；不以禁用拖拽来消除标记。
  计数仅针对动画，排除 Vite 模块预加载观察器及 Playwright 自己的命中监听器。
- 精简回归同时检查演示入口 / 宣传 DOM 不存在、气泡不可见、空反馈零占位、
  Canvas 实际绘字没有旧宣传 / 解释文案、账号入口接近表单；移除演示按钮后，
  动画测试通过真实组件卸载 / 重挂载创建独立场景，不保留隐藏测试按钮。
- 入场回归检查场景左右边界等于视口、卡片跨过右屏幕边缘、落位前辅助区的
  inert / 隐藏及角色不可达、落位后可用；初始整组纵向居中误差小于 1px，
  另验证窗口高度改成 1254px 后仍居中，截图同时包含入场中与到位后。
  大屏增加 1.10 / 1.18 倍整组展示、Canvas 显示分辨率、缩放后真实抓取 / 点击、
  柔光不可命中及矮窗口恢复基准尺寸检查；触控命中下限仍为至少 44px。
- 聚焦回归通过真实 Tab / 输入操作，检查邮箱、验证码、旧 / 新密码的原生层没有额外焦点框、
  原生输入无黑框 / 内阴影、外层只有批准的细边界、透明纹理与稳定位置；覆盖浅 / 深色、手机、强制颜色、
  拖拽恢复后的输入和无 Canvas 原生降级，另检查失焦复原及按钮键盘焦点。
- 自动填充通过 CDP 强制真实 `:autofill` 伪状态（包含浏览器 UA 样式），在合成
  邮箱 / 密码上验证聚焦 / 失焦、浅深色、同色字号、密码遮蔽与退出 autofill 后继续编辑；
  新增不清伪状态、不按任何键时的真实鼠标拖选，通过截图像素变化检查高亮实际绘出，
  并约束输入自身没有阴影。伪状态不等同真实凭据管理器回填，旧像素断言在用户异常持续时也能通过。
  另单独检查原生编辑交接：主指针按下在 mousedown 默认定位前仅原样写回一次，值不变、
  不生成 input / change 事件；普通鼠标编辑零写回。原异常 IAB 在仅 CSS 改动仍失败后，
