Go ORM：查询与更新

创建于 2024-05-21　·　今天 10:30 更新

本文记录使用 GORM 进行数据查询与更新的常见方式，包括条件查询、排序分页、单字段更新与多字段更新，并总结一些容易踩坑的点。

一、查询

以 age > 18 且 name 包含“张”的用户为例，按年龄降序，分页返回：

var users []User err := db. Where("age > ?", 18). Where("name LIKE ?", "%张%"). Order("age desc"). Limit(10).Offset(20). Find(&users).Error if err != nil { // 处理错误 }

二、更新

单字段更新：db.Model(&u).Update("age", 20)

多字段更新时，使用 map 可以明确包含零值。

⚠
易错点
使用 First 查找记录时，找不到会返回错误；而 Find 只会返回空切片。判断是否存在时，选择合适的方法。

在这篇笔记里，如何只更新 name 字段？
可以使用 Update 指定字段和新值：

db.Model(&u).Update("name", "张三")

这样只会更新 name，其他字段不会改动。
Updates(struct) 为什么有些字段不会更新？
因为 struct 中的零值会被视为“未提供”，默认不会更新。若要更新零值，建议使用 map 或 Select 指定字段。
