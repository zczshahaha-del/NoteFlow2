# NoteFlow 单页交互架构地图

日期：2026-11-03，交互修订于 2026-11-06（Asia/Shanghai）。源码核对基线：`b279263`。这是解释当前系统的离线交互页面，不是新的业务入口、实时监控或架构重构。

## 页面与交互

用户希望在同一页面理解模块位置、一次操作经过的环节、传递的数据及最终存储位置。此前四张分散的流程图难以保留这些关系；随后明确要求独立 HTML、完整视觉设计，以及模块自身动效。

[完整 HTML 页面](../../design/noteflow-system-map.html)可直接用浏览器打开，无网络资源依赖。「整个系统」保留 15 个模块和原地展开；选择操作后，进入仅包含相关模块的专属路线。八类操作保留原 106 个示意步骤，共组织为 20 个连续阶段。附件上传单阶段呈现完整路线，另显式画出文件存储，说明文件本体与数据库记录的去向。

阶段导航展示操作从开始到完成的顺序。选择阶段、步骤、模块或箭头编号可直接查看；重复调用的同一模块共用节点，用不同编号说明多次经过。长操作按阶段展开，当前阶段以外的模块不进入当前图。流程图占满内容区，当前接收模块的卡片直接显示收到、处理和得到；其他卡片显示模块名与职责。箭头使用步骤编号和动作名称。连续合成示例保持，示例字段、原因与代码边界通过卡片内的「原因与实现」入口查看，打开时暂停播放，Escape 可关闭。

单步、回退、左右键、4 / 6 / 10 秒播放与等待确认共用控制状态。换步不自动滚动；同一阶段的模块按最长说明预留尺寸，推进时保持卡片位置和尺寸。新增「定位本步」供用户主动定位并暂停播放。操作图没有装饰性循环动效，仅当前箭头上的数据标记移动一次；尊重系统减少动效和全局暂停。全貌里的模块动效继续保留。窄屏将模块纵向排列，说明继续位于当前模块内，保留正常字号和可点击步骤。

[图布局与控制源稿](../../design/noteflow-system-map.source.html)维护全貌与场景调用关系；[操作视图](../../design/noteflow-system-map.flow.js)维护阶段、106 份具体解释与合成示例；[模块内部数据](../../design/noteflow-system-map.details.js)维护全貌展开和来源映射。业务步骤与解释数量在启动时校验。页面不读取现有账号或笔记。

[独立页面模板](../../design/noteflow-system-map.shell.html)提供灰蓝配色、场景侧栏、点阵画布、模块卡片与状态条。小屏改为下拉选择和纵向排列。模块的拼合线段、关联节点、存储层叠、生成波形是装饰性循环动效，文字保持稳定；离开视口暂停，全局可暂停，系统减少动效时默认关闭。它们不表示实际服务健康或生成进度。生成独立页面：

```sh
node scripts/build-system-map.mjs
```

构建脚本把图布局、[子流程数据](../../design/noteflow-system-map.details.js)和页面模板内联到完整 HTML。图源稿不单独打开；完整页不依赖宿主、iframe 或外部资源。没有加入工作台导航、业务路由或生产部署配置，本机静态 HTTP 仅用于查看设计文件。

## 2026-11-06 操作专属路线验收

正常上传实现已核对 AttachmentService 与 LocalObjectStorage。附件服务先写文件，再提交含 storage_key、名称、大小与归属的数据库记录；失败一致性缺口仍保留在对应步骤的边界说明中。草稿、预览、选区采用和记忆来源的原业务边界沿用现有核对结果，合成示例不代表实际生成结果。

隔离 Edge 覆盖八条流程 106 步及回退，阶段导航、步骤与箭头选择，三档计时与创建确认暂停，六种宽度 1440 / 1024 / 736 / 600 / 375 / 320px，浅深色和减少动效。逐段采样所有阶段的线条与编号，未穿过无关节点或盖住节点，页面无横向溢出。正常动效下连续换步的滚动、图高和位置保持一致。键盘焦点、旧状态恢复、宿主回声以及展开实现说明的同步暂停均通过。运行错误和非预期网络请求均为零。内置浏览器刷新并查看附件第 3 步，确认只显示相关模块、文件存储和具体登记结果。

同日模块内说明修订：移除图右侧说明列，流程图改为通栏，模块标题放大，输入 / 处理 / 结果进入当前模块。动作说明和原职责共同参与尺寸预留；头部高度固定，避免标题换行导致跳动。当前模块标题可点击暂停，保持当前步骤。示例字段与实现说明改用可关闭的模态详情，打开后暂停，详情内方向键不推进底层流程。

新增动作标签后，初次回归发现自循环标签会盖住模块，已将自循环改为卡片下方回路。最终隔离 Edge 验证全部 106 步和六种宽度的线条 / 标签避让，逐步核对模块尺寸与位置不变、内容不越界，三档计时和人工确认继续有效；另外覆盖旧状态恢复、宿主回声、键盘焦点、当前模块点击、详情暂停 / Escape 和主动定位。内置浏览器已加载新版附件第 1 步，实际看到模块内说明与动作箭头。实际阅读体验仍待用户试读。

## 模块内部流程已补齐（先前版本记录）

此前交付只完成阅读节奏和连线辨识，未落实展开内容重画。用户指出后，本轮将 15 个模块的旧文字列表全部替换为流程节点，内部数据集中在 `noteflow-system-map.details.js`，避免旧列表与新图形成两份来源。

- 每个展开区先说明职责，再显示“收到什么 → 处理节点 → 交给谁 / 产生什么”，包含合成数据示例和明确箭头。具体失败 / 取消分支用直白结果说明；源码路径、问题编号和实现约束留在折叠详情。
- 共 29 条操作分支、106 个内部节点。笔记模块独立区分手动保存、AI 新建、服务器修改预览和选区快捷改写；快捷改写只在后端生成候选，采用 / 撤销画在前端分支，后续保存另回手动保存。
- 提示词分成识别、回答和写作三个分支，展示规则、用户要求和资料如何组合；记忆区分保存 / 召回，索引区分构建 / 检索，引擎区分提取 / 召回，数据库区分读 / 写。模板、事实引擎、数据库的既有部署边界没有改变。
- 顶层八条流程仍有 106 个对外示意步骤，另用显式映射关联内部模块 / 分支 / 节点。启动时校验映射长度与节点存在性；这是解释用焦点，不是实际调用追踪，也不意味着每个内部节点都有一个独立 HTTP 请求。
- 单步和自动播放共用固定阅读卡，显示当前动作、发送方、接收方、完整数据和模块内的处理。选定场景后卡片按该场景最长步骤留出空间，推进和回退保持画布位置、滚动位置、已展开的模块和分支。
- 点「查看本步内部流程」才展开对应分支，标记“本步”并定位到模块，可从展开区「回到步骤」。多个手动展开可同时保留；点击输入 / 输出模块链接可继续探索。归属连接、外部调用线和内部箭头按展开后的布局重算。
- 图上只给接收模块加橙色描边，橙色箭头和一次性移动标记说明当前方向，蓝色与浅灰分别表示已走过和未走过的路径。完整传递内容在阅读卡里，避免标签盖住短线。阅读时暂停模块装饰动效。

此前展开重画的验收覆盖 15 模块 / 29 分支、笔记四条分支语义、跨模块链接、连线几何、六种宽度及窄屏全部展开。自动展开在当时通过内部节点对应性验证，但用户实际沿「AI 新建笔记」阅读时，换步后的重排和自动滚动让视线丢失。

稳定阅读版在本机 HTTP 的隔离 Edge 验证八条流程 106 步、回退、4 / 6 / 10 秒计时、创建确认暂停、正常动效下的滚动与节点位置、主动定位与返回、320 至 1440px 布局（含 320×520 短屏），运行错误与非预期网络请求为零。实际内置浏览器也核对「AI 新建笔记」连续换步。陌生人的实际理解速度与最终观感待用户验收。

## 阅读节奏与播放辨识改进（先前版本记录）

用户反馈原先每步 2.2 秒难以阅读。旧版虽有“下一步”，缺少返回入口，控制区也容易随长图滚出视野。本轮改为：

- 默认单步，选择路径直接显示第一步，等用户点击才继续；提供上一步 / 下一步，左右方向键支持回看，输入框和下拉框保留原生键盘行为。
- 自动播放独立选择，默认每步 6 秒，可选 4 / 6 / 10 秒。开始 / 恢复不会立即跳过当前步骤；改速度会重新给足当前停留时间；单步、切模式、换场景、页面隐藏会取消旧计时。
- 创建卡片、草稿审阅、修改预览和选区候选四个等待点会主动暂停。只显示“继续演示”，不代替真实业务确认；点击继续后仍停在下一步，可明确选择恢复自动播放。
- 阅读控制与当前说明放在悬浮阅读卡里。视口高度不超过 680px，或宽度低于 560px 且高度不超过 820px 时，卡片随页面滚动以减少遮挡。场景下拉与收起模块在阅读卡外。
- 当前连接用 3.2px 橙色线，最后绘制以避免共享外围路线覆盖。调用实线与读写虚线保留。

阅读节奏那轮保留原 15 模块与 106 个示意步骤，当时内部子流程仍未实施；现已由上节补齐，不将此前未完成状态继续当作当前交付。

本轮证据：隔离 Edge 对最终 HTML 使用受控时钟验证手动停留 120 秒不前进、4 / 6 / 10 秒边界、暂停恢复、切换取消旧计时、三类确认路径自动停留、键盘和宿主快照回声 / 外部恢复。八条路径 106 步及回退通过；1440 / 1024 / 736 / 600 / 375 / 320px 与 320×520 短屏的两种阅读模式无控件越界、无横向溢出，悬浮条位置与短屏回退通过。实际计算色为当前 `rgb(184,93,20)`、完成 `rgb(76,136,173)`，当前线宽 3.2px；浅深色截图核对，运行错误与非预期网络请求为零。初次测试误选桌面隐藏下拉、并把短屏的非悬浮条也按悬浮高度验收，已修正夹具并复跑，不通过强制点击绕过实际入口。临时证据在 `/tmp/noteflow-map-reading-*`。

当前本机 HTTP 预览返回 200；另用真实计时确认开启自动播放后 2.5 秒仍停在原步，累计 6.2 秒后才进入下一步，暂停正常；当前连接是最后绘制的数据路径，运行错误为零。此检查无受控时钟，不调用业务接口。

## 图中关键关系

- 前端不直连数据库。聊天、保存、选区快捷修改与附件有不同入口，普通保存不需要模型判断意图。
- 对话 Planner 让模型提出计划，再由程序校验；全库采用固定计划。缺信息、出错或无来源时不会沿成功路径假装继续。
- 普通聊天的个人记忆读取受开关和计划约束；当前笔记 / 选区问答与全库问答跳过个人记忆召回。聊天示例明确以存在有效记忆为前提，非每次必经步骤。
- “提示词拼装”将多处现有函数按职责合并展示，尚非独立平台。识别、回答、写作是不同模型调用；索引嵌入直接接收文本，不伪装成聊天提示词。
- 新建要经过卡片、大纲、章节、草稿审阅与确认保存。服务器修改预览先独立落库再应用；选区快捷修改只返回候选文字，采用后走普通自动保存。
- NoteFlow PostgreSQL 保存正文、版本、草稿、预览、会话、运行 / 检查点、来源控制、规则、队列、检索派生数据及附件元数据。文件本体在磁盘 / 卷；Hindsight 自己的数据库保存事实、关系与来源原文。Redis 在入口详情中作为限流存储标出，不与正文库混淆。
- 记忆管理检查允许保存 / 使用的来源和状态。后台从持久队列领取后复查开关、规则版本、来源代数，经 MemoryEngine 和 Hindsight 适配器调用引擎。返回事实仍要经过项目过滤。
- LangGraph / 业务运行记录协助推进与恢复，不拥有唯一正文。索引、草稿、Outbox worker 当前随 FastAPI 同进程启动，不画成已部署的微服务。
- 当前正式事实引擎只有 Hindsight；旧 Mem0 的本地事实索引兼容路径在适配接口边界中说明，未虚构为可直接切换的第二引擎。

连线按职责说明调用、返回或读写，不是逐函数调用栈；新建示例跨越多次用户点击与 HTTP 请求。动画是源码核对后的示意，不表示实际耗时、当前任务或真实模型执行日志。

## 验证与证据

- 直接打开最终 HTML + 隔离无头 Microsoft Edge，不使用用户浏览器配置或登录态。
- 1440 / 1024 / 736 / 600 / 375 / 320px 全貌、记忆展开、代码边界与统一收起；736 / 320px 真实鼠标逐个展开全部 15 个模块与代码边界，无横向溢出、按钮重叠或控件 / 代码越界。窄屏纵向排列，不缩小文字硬塞全图。
- 八条路径共 106 步完成；当前连线与两端同步。全库跳过记忆；普通保存 / 选区快捷修改 / 附件跳过 Planner；附件不经过模型；快捷改写与服务器预览的保存边界分别检查。
- 数据标记确实移动；自动播放跨计时周期推进，暂停后不再推进；Enter 单步、侧栏 / 下拉同步、深色、减少动效通过。可见模型模块的波形确实变化，全局暂停后其 animationPlayState=paused；系统减少动效时开关禁用。
- 连线逐条采样。初次数据库返回 API 的线穿过中央模块；窄屏展开时也曾因模块高度误判相邻关系。现根据实际列数 / 节点顺序判定，按整行底部与外围布线，六宽度及全部展开时不穿过无关模块。这是解释页布局修正，不是业务路径故障。
- 运行错误与非预期网络请求为 0。源稿 / 模板 / 生成页语法、源码路径、生成可重复性与 Git 空白检查在提交前执行。
- 临时检查脚本、结果与截图在 `/tmp/noteflow-map-*`，不提交缓存。产品代码未变，没有重跑产品构建 / 后端测试、真实模型 / 邮件或生产部署。

早期片段检查的共享 iframe 包装器会同步回传状态，曾重入恢复并误停播放，已隔离自身快照回声并另测外部状态恢复。多次手改 iframe 高度后的鼠标检查也曾失败，不能计作通过证据；最终交付为无 iframe 的独立页面，上述鼠标与流程验收全部在最终 HTML 重跑通过。最终观感与理解度待用户确认。
