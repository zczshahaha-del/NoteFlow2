# NoteFlow 单页交互架构地图

日期：2026-11-03（Asia/Shanghai）。源码核对基线：`b279263`。这是解释当前系统的离线交互页面，不是新的业务入口、实时监控或架构重构。

## 页面与交互

用户希望在同一页面理解模块位置、一次操作经过的环节、传递的数据及最终存储位置。此前四张分散的流程图难以保留这些关系；随后明确要求独立 HTML、完整视觉设计，以及模块自身动效。

[完整 HTML 页面](../../design/noteflow-system-map.html)可直接用浏览器打开，无网络资源依赖。[图与数据源稿](../../design/noteflow-system-map.source.html)包含 15 个可展开模块和八条操作路径：普通聊天、全库问答、手动保存、AI 新建、服务器修改预览、选区快捷修改、保存记忆、上传附件。默认显示全貌；选择场景保留所有模块位置，停在第一步并默认单步阅读。上一步 / 下一步、可选自动播放和键盘共享状态；当前连线有一次性移动标记，不自动循环整条流程。展开时其余模块移动，连线随位置重算；可统一收起。

点击模块原地展开内部步骤，再展开“代码与当前边界”查看实现位置与遗留事项；点击连线查看所传数据。选择、步骤与展开状态可由对话宿主恢复。页面没有 fetch、XHR、WebSocket 或业务接口调用，不读取现有账号或笔记。

[独立页面模板](../../design/noteflow-system-map.shell.html)提供灰蓝配色、场景侧栏、点阵画布、模块卡片与状态条。小屏改为下拉选择和纵向排列。模块的拼合线段、关联节点、存储层叠、生成波形是装饰性循环动效，文字保持稳定；离开视口暂停，全局可暂停，系统减少动效时默认关闭。它们不表示实际服务健康或生成进度。生成独立页面：

```sh
node scripts/build-system-map.mjs
```

构建脚本合并图的基础布局和页面模板。完整页不依赖对话宿主或 iframe；源稿另保留对话预览能力。没有加入工作台导航、业务路由或生产部署配置，本机静态 HTTP 仅用于查看设计文件。

## 阅读节奏与播放辨识改进

用户反馈原先每步 2.2 秒难以阅读。旧版虽有“下一步”，缺少返回入口，控制区也容易随长图滚出视野。本轮改为：

- 默认单步，选择路径直接显示第一步，等用户点击才继续；提供上一步 / 下一步，左右方向键支持回看，输入框和下拉框保留原生键盘行为。
- 自动播放独立选择，默认每步 6 秒，可选 4 / 6 / 10 秒。开始 / 恢复不会立即跳过当前步骤；改速度会重新给足当前停留时间；单步、切模式、换场景、页面隐藏会取消旧计时。
- 创建卡片、草稿审阅、修改预览和选区候选四个等待点会主动暂停。只显示“继续演示”，不代替真实业务确认；点击继续后仍停在下一步，可明确选择恢复自动播放。
- 阅读控制与当前说明放在悬浮阅读条里，滚动时仍可操作。短于或等于 600px 的视口取消悬浮，避免大块遮住图。场景下拉与收起模块留在阅读条外，手机按钮至少 44px。
- 当前连接改为橙色 3.2px 粗线，两端模块同步描边；已走过的连线用蓝色，未经过用浅灰。调用实线 / 读写虚线仍保留原语义；当前连接最后绘制，避免共享外围路线被覆盖。

本轮保持原 15 模块与 106 个示意步骤；模块内部按不同操作重画为子流程，仍属于下一轮待实施的内容，不将阅读控制改进当成内部流程重构已经完成。

本轮证据：隔离 Edge 对最终 HTML 使用受控时钟验证手动停留 120 秒不前进、4 / 6 / 10 秒边界、暂停恢复、切换取消旧计时、三类确认路径自动停留、键盘和宿主快照回声 / 外部恢复。八条路径 106 步及回退通过；1440 / 1024 / 736 / 600 / 375 / 320px 与 320×520 短屏的两种阅读模式无控件越界、无横向溢出，悬浮条位置与短屏回退通过。实际计算色为当前 `rgb(184,93,20)`、完成 `rgb(76,136,173)`，当前线宽 3.2px；浅深色截图核对，运行错误与非预期网络请求为零。初次测试误选桌面隐藏下拉、并把短屏的非悬浮条也按悬浮高度验收，已修正夹具并复跑，不通过强制点击绕过实际入口。临时证据在 `/tmp/noteflow-map-reading-*`。

当前本机 HTTP 预览返回 200；另用真实计时确认开启自动播放后 2.5 秒仍停在原步，累计 6.2 秒后才进入下一步，暂停正常；当前连接是最后绘制的数据路径，运行错误为零。此检查无受控时钟，不调用业务接口。

## 图中关键关系

- 前端不直连数据库。聊天、保存、选区快捷修改与附件有不同入口，普通保存不需要模型判断意图。
- 对话 Planner 让模型提出计划，再由程序校验；全库采用固定计划。缺信息、出错或无来源时不会沿成功路径假装继续。
- 普通聊天的个人记忆读取受开关和计划约束；当前笔记 / 选区问答与全库问答跳过个人记忆召回。聊天示例明确以存在有效记忆为前提，非每次必经步骤。
- “提示词拼装”将多处现有函数按职责合并展示，尚非独立平台。识别、回答、写作是不同模型调用；索引嵌入直接接收文本，不伪装成聊天提示词。
- 新建要经过卡片、大纲、章节、草稿审阅与确认保存。服务器修改预览先独立落库再应用；选区快捷修改只返回候选文字，采用后走普通自动保存。
- NoteFlow PostgreSQL 保存正文、版本、草稿、预览、会话、运行 / 检查点、来源控制、规则、队列、检索派生数据及附件元数据。文件本体在磁盘 / 卷；Hindsight 自己的数据库保存事实、关系与来源原文。Redis 在入口详情中作为限流存储标出，不与正文库混淆。
- 记忆管理检查允许保存 / 使用的来源和状态。后台从持久队列领取后复查开关、规则版本、来源代数，经 MemoryEngine 和 Hindsight 适配器调用引擎。返回事实仍要经过项目过滤。
- LangGraph / 业务运行记录协助推进与恢复，不拥有唯一正文。索引、草稿、Outbox worker 当前随 FastAPI 同进程启动，不画成已部署的微服务。
- 当前正式事实引擎只有 Hindsight；旧 Mem0 的本地事实索引兼容路径在适配接口边界中说明，未虚构为可直接切换的第二引擎。

连线按职责说明调用、返回或读写，不是逐函数调用栈；新建示例跨越多次用户点击与 HTTP 请求。动画是源码核对后的示意，不表示实际耗时、当前任务或真实模型执行日志。

## 验证与证据

- 直接打开最终 HTML + 隔离无头 Microsoft Edge，不使用用户浏览器配置或登录态。
- 1440 / 1024 / 736 / 600 / 375 / 320px 全貌、记忆展开、代码边界与统一收起；736 / 320px 真实鼠标逐个展开全部 15 个模块与代码边界，无横向溢出、按钮重叠或控件 / 代码越界。窄屏纵向排列，不缩小文字硬塞全图。
- 八条路径共 106 步完成；当前连线与两端同步。全库跳过记忆；普通保存 / 选区快捷修改 / 附件跳过 Planner；附件不经过模型；快捷改写与服务器预览的保存边界分别检查。
- 数据标记确实移动；自动播放跨计时周期推进，暂停后不再推进；Enter 单步、侧栏 / 下拉同步、深色、减少动效通过。可见模型模块的波形确实变化，全局暂停后其 animationPlayState=paused；系统减少动效时开关禁用。
- 连线逐条采样。初次数据库返回 API 的线穿过中央模块；窄屏展开时也曾因模块高度误判相邻关系。现根据实际列数 / 节点顺序判定，按整行底部与外围布线，六宽度及全部展开时不穿过无关模块。这是解释页布局修正，不是业务路径故障。
- 运行错误与非预期网络请求为 0。源稿 / 模板 / 生成页语法、源码路径、生成可重复性与 Git 空白检查在提交前执行。
- 临时检查脚本、结果与截图在 `/tmp/noteflow-map-*`，不提交缓存。产品代码未变，没有重跑产品构建 / 后端测试、真实模型 / 邮件或生产部署。

早期片段检查的共享 iframe 包装器会同步回传状态，曾重入恢复并误停播放，已隔离自身快照回声并另测外部状态恢复。多次手改 iframe 高度后的鼠标检查也曾失败，不能计作通过证据；最终交付为无 iframe 的独立页面，上述鼠标与流程验收全部在最终 HTML 重跑通过。最终观感与理解度待用户确认。
