# NoteFlow 产品可用性审查 · 2026-10-25

源码基线：`6cf4c64`。本轮检查登录、注册、找回密码入口，以及工作台的知识库、正文、搜索、AI、设置、备份与回收站。结论包含 32 项观察，分为已复现问题、源码确认缺口和设计建议；不是 32 个新漏洞。

## 结论

当前最值得优先投入的是操作闭环：失败后能否继续、菜单是否点得到、AI 结果能否找回、备份是否能恢复原来的知识库。暖白灰蓝、轻量正文、无外框 AI 回复、连续侧栏、阅读章节跟随、聊天输入自增高和部分失败重试已经存在，应保留这些成果。

建议先处理 A01 / A02、B01 / B02 / B03、D01、E01 / E02、F01，再精修视觉与动效。不能用整页换皮代替这些修复，也不把此前用户退回的 V11 恢复为实施方案。

优先级：P1 为直接阻断操作、损害数据可信度或容易误操作；P2 为明显影响理解、效率和舒适度。既有上线安全风险单列为发布门槛，不与 UI 建议混算。

## 检查方法与边界

- 实际使用本机 `127.0.0.1:5173` 的 Edge 已登录工作台与独立 IAB 登录页。检查桌面、1280×800、1280×480、390×844、320×568 等视口；多数操作在独立审查标签页完成。
- 实际打开搜索、知识库、新建菜单、文件菜单、本文目录、AI 模式菜单、账号菜单、设置各分类及回收站；没有新建、修改、恢复或删除真实笔记，没有发送邮件、认证提交或真实模型请求。
- 登录发码失败、认证挂起、JSON 导出后再解析、搜索摘要使用正式 React / 服务 / 工具代码和合成输入验证。全部 fetch 被替身拦截，复现命令为 `node scripts/product-usability-audit.mjs`。
- “实测”只说明列明的本机条件；“源码”不等于生产故障已发生；“建议”是产品判断，仍需局部设计评审。没有测量实体设备帧率、软键盘、读屏、Safari / Firefox、真实弱网与生产恢复。
- 视口改变后的过渡帧曾显示离场面板，不能据一张中间截图断言持续越界；IAB 一次截图尺寸与 DOM 视口不同，改用完整页面截图核对，未当作产品缺陷。设置页一次消失未形成可控复现，也未计入问题。

## UI 与动效的具体方向

1. **先统一状态，再加装饰。** 菜单出现时应能立即操作，关闭后应找回原位置；加载、失败、未加载、禁用和已完成必须有可区分的视觉与语义。低对比的“已完成”禁用按钮不能替代结果入口。
2. **保留现有温和基调。** 源码已接入共享控件变量与暖白灰蓝，不再重复提出“从零建立设计系统”。本轮最明显的细节差异是登录 11px 的反馈 / 12px 的辅助入口与工作台较易读的正文及控件之间的节奏；需要按使用场景调整，而不是全站统一放大字号。
3. **让动效服务连续操作。** 沿用同一侧栏入口连续移动、减少动效回退和输入稳定几何；菜单应在当前层开合、边缘时翻转，不能在 Escape 后整栏消失。主按钮按下反馈和任务结束后的结果衔接，比再加渐变 / 阴影更有价值。
4. **返回用户与首次用户分开验收。** 首次可以完整展示小人入场；回访、错误重试和模式切换优先保证效率。任何缩短入场的方案先出局部对照，不擅自修改已批准视觉。
5. **建立手感验收样本。** 逐项覆盖快速连续开关 / 中途反向、鼠标与键盘、长标题 / 长错误、输入法、深色 / reduced-motion、窄屏 / 低高度。当前已有不少相关测试，本轮未取得全链路帧时间与实体触控数据，不能承诺“稳定 60fps”或把 CSS 时长当成丝滑证据。

规范依据：模态的初始焦点、Tab 圈定、Escape 和背景不可交互参照 [W3C APG Modal Dialog](https://www.w3.org/WAI/ARIA/apg/patterns/dialog-modal/)。[WCAG 2.2 AA 目标尺寸](https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum.html)的基准为 24×24 CSS px 并有例外；44×44 是 [增强目标尺寸 AAA](https://www.w3.org/WAI/WCAG22/Understanding/target-size-enhanced.html)及本报告的触控舒适目标，不能混为同一门槛。[交互动效指南](https://www.w3.org/WAI/WCAG22/Understanding/animation-from-interactions.html)支持减少非必要运动；当前产品已有相关回退，本轮不重复列为缺失。
